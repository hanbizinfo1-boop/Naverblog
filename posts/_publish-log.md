# 발행 원장 (publish log)

레포에 있는 글이 **실제로 네이버에 올라갔는지**를 기록하는 단 하나의 기준 파일이다.
`_variation-log.md` 가 "어떻게 썼나"를 남긴다면, 이 파일은 "올렸나"를 남긴다.

## 상태 값

| 값 | 뜻 |
|---|---|
| `미확인` | 레포에는 있으나 네이버 발행 여부를 확인하지 못함 (초기값) |
| `발행완료` | 네이버에 발행됨. 발행일과 URL 을 반드시 함께 적는다 |
| `대기` | 작성은 끝났고 아직 올리지 않음 (발행 예정) |
| `보류` | 팩트체크·보이스 검수에서 걸려 발행하지 않기로 함 |

## 기록 규칙

- 글을 **발행한 직후** 해당 행의 상태·발행일·URL 을 채운다. 나중에 몰아서 적지 않는다.
- URL 은 `https://blog.naver.com/{아이디}/{logNo}` 형태의 실제 주소를 적는다.
- 새 글을 쓰면 `_variation-log.md` 와 이 파일에 **동시에** 행을 추가한다.
- 작성일은 파일명의 날짜, 발행일은 네이버에 실제로 올라간 날짜다. 둘은 다를 수 있다.
