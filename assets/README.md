# 고정자산 (assets)

블로그 글에 반복해서 쓰는 이미지다. **생성하거나 스톡으로 대체하지 않는다.**
생성하면 허위가 되거나(기관 로고·정부 홍보물) 브랜드가 훼손된다(박성제·한비즈).

원본은 `바탕화면\짤 모음` 과 `바탕화면\작업공간\짤모음` 에 그대로 있다.
여기 있는 건 복사본이라 원본을 건드리지 않았다.
