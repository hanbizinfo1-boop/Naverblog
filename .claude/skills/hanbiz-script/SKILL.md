# 한비즈 유튜브 대본 작성 스킬 (완전체)

## 이 스킬은 무엇인가

박성제 대표가 직접 출연하는 유튜브 영상 대본을
**대표님 톤 그대로**, **시청자가 끝까지 보고 행동하게** 만드는 시스템.

## 워크플로우 (반드시 이 순서로)

### STEP 1. 사용자 요청 받기

사용자가 다음 중 하나를 입력한다:
- 주제 + 콘텐츠 유형 (인터뷰/풀링/키/숏폼)
- 다른 유튜브 대본 + "이 구조로 우리 톤으로 바꿔줘"
- 실제 사례 정보 (클라이언트 케이스, 숫자, 결과)

### STEP 2. (필요시) 추가 정보 받기

다음이 빠져있으면 1~3개 질문으로 받는다:
- 어떤 회사 채널인지 (한국중소기업 비즈니스센터)
- 콘텐츠 유형 (인터뷰/풀링/키/숏폼)
- 핵심 메시지 또는 사례 디테일
- 후킹 제목 방향

### STEP 3. 제목 후보 3개 + 대본 초안 작성

- 후킹 제목 3개 제시 (1개 추천)
- 대본 초안 (이 스킬의 모든 톤앤매너 규칙 적용)
- 출력은 인터뷰 대화 형식

### STEP 4. 컨펌 받기

대본 끝에 항상 묻는다:
"이 대본 마음에 드시면 워드 파일 2종(디자인용/프롬프터용)으로 뽑아드릴까요? 수정 포인트 있으면 말씀해주세요."

### STEP 5. 수정 반영 (있을 경우)

사용자가 수정 요청하면 톤앤매너 규칙 다시 점검하며 반영.

### STEP 6. 컨펌 후 워드 2개 파일 자동 생성

컨펌 떨어지면 즉시 두 파일 생성:
1. `01_[주제]_디자인.docx` (인터뷰어/PD용)
2. `02_[주제]_프롬프터.docx` (촬영 프롬프터용)

생성 코드는 `scripts/` 폴더의 템플릿 사용.

# PART A. 콘텐츠 유형 정의

## A-1. 인터뷰 콘텐츠 (메인 포맷)

**목적**: 실제 사례 또는 정보 전달을 시트콤형 대화로 풀어 끝까지 보게 만든다.

**구조**: 8단계 (PART B 참조)

**분량**: 5~9분

**용도**: 성제관 유튜브 채널, 홈페이지 업로드

## A-2. 풀링 콘텐츠

**목적**: 최대한 많은 사람을 끌어당긴다. "이 사람 뭔가 하는 사람이다"까지만 인식.

**특징**:
- 과하지 않고 은근한 어필만(예를들어, 저도 한국중소기업 비즈니스센터 운영하잖아요, 저도 컨설팅 하다보면~)
- 관점, 사고방식, 문제 제기
- 댓글, 저장, 공유 목표

**엔딩**: 철학적 질문

**분량**: 5~7분 (1200~1500자)

## A-3. 키 콘텐츠

**목적**: 모인 사람 중 정확한 타겟만 골라낸다. "이거 나 얘긴데?" 자각.

**특징**:
- 홍보 가능 (단, 설명식 X)
- 불편해도 됨
- 걸러지는 사람 많을수록 성공

**엔딩**: 4단계 (타겟 지목 → 문제 재확인 → 해결 주체 포지셔닝 → 행동 요청)

**분량**: 8분 이상

## A-4. 숏폼

**목적**: 무조건 유입. 자극만 주고 끝.

**특징**: 홍보 X, 설명 X, 해결책 X. 문제만 던지고 끊는다.

**엔딩**: 미완성. "이거 모르면..." (끊김)

**분량**: 40초 이내 (150~200자)

# PART B. 인터뷰 대본 8단계 구조

### 1단계: 콜드 오프닝 (시트콤형)

**절대 본론으로 바로 시작하지 마라.**

실제 사건/대화처럼 시작해서 시청자가 "어? 뭐지?" 하며 빨려들게 한다.

좋은 예:
```
A: 관장님 어제 사기업체 아니냐고 민원 들어왔어요.
대표: 어? 진짜? 뭐라 하셨어요?
A: 저희 회사 불법이냐던데요?
대표: ㅋㅋㅋ 그래서 뭐라고 하셨어요?
A: 당연히 아니라고 했죠! 근데 답하다 보니까 사람들이 이 부분 많이 궁금해할 것 같더라구요!
대표: 오케이! 오늘 영상 진짜 짧고 굵게 갈게요.
```

또는 사례형:
```
대표: 1년 동안 광고란 광고 다 해보시고, 사기도 당해보시면서 고생하시던 대표님이 계셨어요.
       1년간 가맹점 딱 1개 모집하시고, 브랜드 접기 직전에 저희한테 문의 주셨거든요.
A: 1년에 1개요? 상황이 많이 안 좋으셨네요.
```

나쁜 예:
```
대표: 안녕하세요. 오늘은 정책자금 사기에 대해 알려드리겠습니다.
```

### 2단계: 두괄식 핵심 정보

영상 시작 1~2분 안에 시청자가 영상 본 값을 했다고 느끼게 핵심 정보 줘버린다.

"여기까지만 봐도 본 값 하셨어요" 라는 멘트로 보상감 강조.

### 3단계: CTA #1 (보상 후 부탁)

핵심 정보 주고 나서 자연스럽게:
```
그래서 부탁 하나만 드릴게요.
이런 정보 계속 영상으로 올리고 있는데
도움되셨다 싶으시면 구독 한 번만 눌러주세요.
저한테 진짜 큰 힘이 됩니다.
```

또는 더 직설적으로:
```
구독 누르면 돈 버시는 겁니다!
```

### 4단계: 본론 확장 (Why → How → What)

**Why → How → What 순서**로 풀어라.

각 항목마다 **시각화된 비유** 1개씩 사용:
- "정책자금이 나라 돈인데 누가 무조건 줘요?" → 약함
- "집 가다 발에 돌 걸려서 무조건 넘어집니다 라고 하는 거랑 똑같습니다" → 강함

### 5단계: 차별점 자연스럽게 깔기

회사 자랑은 직원 캐릭터(A)가 놀라는 형태로:
```
대표: 저희는 일단 돈 안 받고 시작합니다.
A: 네? 돈을 안 받아요?
대표: 네. 자금이 실행되기 전까지...
A: 그건 저희한테 너무 손해 아니에요?  ← 직원이 회사 걱정
대표: 손해죠. 그래서 저희도 아무나 안 받아요.  ← 자신감 있게 받음
```

### 6단계: CTA #2 (자존감 보상형)

```
여기까지 보고 계신 대표님이시면
진짜 정보 잘 챙기시는 분이세요.
구독 한 번만 눌러주시면...
```

### 7단계: 추가 가치 + 케미 농담

마케팅팀, 자금 후 매출 지원 등 추가 가치를 가볍게.
이때 **인터뷰어와의 케미 농담** 끼워넣기:
```
대표: 그래서 마케팅팀 있잖아요. 퇴사하지 마요? ㅋㅋ
A: ㅋㅋㅋ 넵!
```

### 8단계: 마무리 CTA #3 + 액션

```
혼자 하실 수 있으시면 직접 하시는 게 제일 좋아요. 진심입니다.
근데 [상황 1], [상황 2], [상황 3] 이라면
저희한테 연락 한 번 주세요.
될 수 있는 건 확실하게 잡아드리고요.
안 되는 건 솔직하게 "안 됩니다" 라고 말씀드리겠습니다.
구독하면 돈 버시는 거구요.
다음 영상에서 뵐게요! (손 ㅂ2ㅂ2)
```

# PART C. 화자 설정

## 대표 (박성제 관장)

- 직설적, 거침없음
- 본인 감정 표현은 날것 ("욱했어요", "속 터지더라고요", "이가 갈립니다", "선을 넘어버렸습니다")
- 고객 깎아내리지 않음 (단, 사기꾼/브로커는 신랄하게 비판 가능)
- 자조 위트 자주 사용 ("저희가 보험 팔 줄도 모릅니다 ㅋㅋ")
- 시청자한테 도발적 직접 화법 ("당신은 ~", "같이 불법하시려고요?")
- 본인 경험 솔직하게 ("저도 이걸 몰라서 매출이 덜 나지 않았을까 싶어요")

## A (인터뷰어, 여성)

- 얼굴 노출 X (오프 보이스 또는 어깨 너머 실루엣)
- **단순 질문자가 아니라 회사 직원 캐릭터**
- 진짜 놀란 듯한 리액션 ("엥?", "와...", "진짜요?")
- 시청자 감정을 대신 표현 ("개싫어요 ㅋㅋ", "본인이 불법한다고 광고하네 ㅋㅋㅋ")
- 대표와의 케미 활용 ("퇴사하지 마요?" 같은 농담 받아주는 역할)

A의 대사는 다음 4가지 중 하나여야 한다:
1. **시청자 대리 질문** ("4가지가 뭔데요?")
2. **시청자 감정 대리** ("개싫어요 ㅋㅋ", "와 정부가 작정했네요")
3. **회사 직원으로서 놀람** ("그건 저희한테 손해 아니에요?")
4. **케미 농담 받아주기** ("ㅋㅋ 넵!")

# PART D. 톤앤매너 규칙

## D-1. 표현 강도 변환표

추상적 → 시각적, 약함 → 강함:

| 약함 (사용 금지) | 강함 (이걸로) |
|---------------|------------|
| 위험한 사람 | 뉴스 나올 사람 |
| 안 좋은 결과 | 빨간 줄 다이렉트로 그어짐 |
| 도움이 됩니다 | 돈 버시는 겁니다 |
| 사업이 어려워집니다 | 망합니다 |
| 의심스럽습니다 | 거짓말하는 거예요 |
| 효과가 있습니다 | 매출이 4배 뛰었어요 |

## D-2. 시각화 비유 라이브러리

추상 개념 → 즉시 그림 그려지는 일상 비유로 변환:

- 광고 = 소개팅
- 가맹 모집 = 첫 만남에서 연봉 자랑하는 사람
- 무조건 승인 = 발에 돌 걸려서 넘어진다는 약속
- 컨설팅 사칭 = 보험 팔러 온 사람
- 라인 있다는 사람 = 본인이 불법한다고 광고하는 사람
- 제품은 택시다 = 목적지(결과)가 중요하지, 택시(제품) 자체가 중요한 게 아니다
- 직접 어필 = 동호회에서 돈 자랑하는 남자

비유 없는 대본은 기억되지 않는다. **모든 대본에 핵심 비유 최소 1개 필수.**

## D-3. 표기 규칙

다음 표기 적극 사용 (날것성):
- ㅋㅋ, ㅋㅋㅋ, ㅋㅋㅋㅋ (강도 조절)
- ???? !!! 같은 강조
- "걍" 같은 인터넷 줄임말
- "(손 ㅂ2ㅂ2)" 같은 액션 표기
- "엥?" "오?" "와..." 같은 리액션 단어

## D-4. 문장 호흡

- 한 문장 15자 이내가 이상적
- 20자 넘으면 끊어라
- 마침표 많이 써라
- 짧게. 끊어서. 리듬감 있게.

## D-5. 궁금증 루프 (본론 전개)

```
궁금증 A 제시
→ A 핵심 해결 (50%만, 전부 말하지 않음)
→ 전환 문장: "근데 여기서 더 무서운 게 있어요"
→ 궁금증 B 제시
→ B 해결 (50%만)
→ 전환 문장: "이게 진짜 문제예요"
→ 궁금증 C (클라이맥스)
→ 핵심 깨달음 한 방
```

## D-6. 중간 이탈 방지 문장 (최소 3개 사용)

- "여기서 대부분 갈립니다"
- "이 지점에서 결과가 완전히 달라져요"
- "근데 여기서 진짜 문제가 있습니다"
- "이건 제가 직접 겪은 건데요"
- "여기서부터가 중요해요"
- "이거 놓치면 다시 원점이에요"

## D-7. 절대 금지

- "안녕하세요"로 시작 (콜드 오프닝 깨짐)
- "오늘은 ~에 대해 알려드리겠습니다" (설명조)
- 어려운 단어 그대로 사용 ("제3자 부당개입 TF" → "전담팀")
- 정중한 부탁 일변도 ("도움이 되시면 구독 부탁드립니다")
- 고객 비하 ("그분은 잘 모르셨어요", "버릇이었어요")
- 과시 ("저희가 최고입니다", "1등입니다")
- 이모지 사용
- 따옴표 남용
- "여러분"/"당신" 호칭 (대신 "~하시는 대표님들", "~하시는 분들")
- FOMO 표현 ("같은 동네 같은 업종 1곳만," "옆 가게가 먼저 하면 못한다")

## D-8. 반드시 포함

- 콜드 오프닝 (실제 사건처럼 시작)
- 시각화 비유 최소 1개
- 인터뷰어 케미 농담 최소 1개
- CTA 3회
- 자조 위트 최소 1개 ("저희가 보험 팔 줄도 모릅니다")
- 시청자 향한 도발적 직접 화법 최소 1회
- 마무리 액션 표기
- 중간 이탈 방지 문장 최소 3개

# PART E. 제목 공식

## 좋은 제목 패턴

1. **숫자 대비형**: "1년간 가맹점 1개 모집하던 본사, 한 달 만에 3개 계약"
2. **금기/비밀형**: "정책자금 브로커 10초 만에 거르는 법, 4가지만 외우세요"
3. **정체성 타격형**: "이 4가지 멘트 들으면 바로 끊으세요"
4. **반전 스토리형**: "망해가던 마사지샵이, 광고비 올리자고 했더니 욕하시던 원장님"

## 제목 조건

- 15~20자 이내

# PART G. 표절 방지 (다른 유튜브 대본 참고 시)

사용자가 다른 유튜브 대본을 던져주고 "우리 톤으로 바꿔줘" 하면:

## 절대 하지 마라

- 원본 예시 그대로 사용
- 동일한 숫자, 순서, 비유
- 동일한 상황 설정
- 동일한 롤플레이 대사
- 원본 화자의 개인 경험 그대로

## 반드시 하라

1. 원본이 왜 잘 됐는지 **구조**만 추출
2. 핵심 인사이트를 **새로운 비유**로 재해석
3. 예시는 **다른 산업/상황**으로 치환
4. 숫자는 다른 체계 사용
5. 롤플레이는 완전히 새로운 상황으로

## 기준

"영감 받았다고는 할 수 있지만, 베꼈다고는 절대 말할 수 없는 콘텐츠"

# PART I. 워드 파일 생성 (컨펌 후)

사용자 컨펌 떨어지면 즉시 두 파일 생성.

## I-1. 디자인 워드 (인터뷰어/PD용)

**파일명**: `01_[주제키워드]_디자인.docx`
**스크립트**: `scripts/make_design_doc.js` 참조

**특징**:
- 네이비(#1A2332) + 골드(#C9A961) + 라이트베이지(#F5F3EE) 톤
- 상단 헤더: "한국중소기업 비즈니스센터" 또는 "HANBIZ MARKETING" 라벨
- 제목 큰 글씨 (32pt, 네이비)
- 좌우 2단 박스: 촬영 구성 / 핵심 강조점
- 대본 테이블: 화자 칼럼 + 대사 칼럼
  - A는 흰 배경, 회색 화자 라벨
  - 대표는 라이트베이지 배경, 네이비 화자 라벨
  - [CTA #N] 구간은 화자 칼럼에 명시
- 푸터: 회사명 + 핵심 숫자

## I-2. 프롬프터 워드 (촬영용)

**파일명**: `02_[주제키워드]_프롬프터.docx`
**스크립트**: `scripts/make_prompter_doc.js` 참조

**특징**:
- 흰 배경, 검정 텍스트 (디자인 일체 없음)
- 대표 대사: **18pt 큰 글씨**, 한 호흡씩 줄바꿈
- 같은 답변 안에서는 **빈 줄 없음** (호흡만 끊김)
- 인터뷰어 큐(A 질문)는 **작은 회색 11pt 이탤릭** + [A] 표시
- A 질문 위 공백 600 / 아래 공백 480 (질문↔답변 명확 분리)
- CTA 구간은 **금색 굵은 글씨로 구분선** + 위 공백 480

## I-3. 두 파일 동시 생성 명령

scripts 폴더의 두 템플릿을 사용해 한 번에 생성:

```bash
node scripts/make_design_doc.js [주제키워드]
node scripts/make_prompter_doc.js [주제키워드]
```

생성 후 `present_files`로 두 파일 동시 출력.
