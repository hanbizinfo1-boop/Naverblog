# 박관장 보이스 린터 (park-voice-linter)

naver-seo-geo-blog가 쓴 글(또는 회원님이 직접 쓴 글)을 받아
**박관장 보이스 규칙 위반을 자동 채점**하는 검수 전용 스킬이다.
글을 새로 쓰지 않는다. 오직 점검·지적·수정안만 낸다.

## 채점 항목 (항목별 PASS/FAIL + 위반 위치)

### 1. 문체 금지 (치명적 — 1개라도 FAIL이면 발행 보류)
- [ ] 큰따옴표 `""` · 작은따옴표 `''` 인용구 **0개**
- [ ] 이모지 0개 (단 ㅎㅎ; (?) (...) 텍스트 구두점은 글당 2회까지 허용 → 초과 시 FAIL)
- [ ] 마크다운 문법(**, ##, 불릿, 화살표 등) 0개

### 2. 호칭·어미
- [ ] 금지 호칭(사장님 / 김대표님·박대표님 등 성+대표님 / 여러분 / 사장님들) **0개**
- [ ] 박관장 1인칭(제가/저희가) 시점 처음~끝 유지
- [ ] 어미가 회상조(~그러시더라고요/~말씀드렸는데/~들어보니까)로 자연스러운가

### 3. 자연스러움 (v6.0 핵심)
- [ ] **문장 길이 변주(burstiness)**: 짧은 문장(5~12자)과 긴 문장(30~45자)이 섞여 있는가
      → 모든 문장이 비슷한 길이면 FAIL (로봇 신호)
- [ ] **소리내어읽기**: 말로 읽어 걸리는 문장 없는가
- [ ] 추상 형용사(효과적인/다양한/종합적인/체계적인/최적의) 0개

### 4. 비유 (조건부)
- [ ] 비유 **0~1개**. 2개 이상이면 FAIL
- [ ] 있는 비유가 "박관장이 현장에서 실제로 쓸 법한가" — 억지면 FAIL → 삭제 권고

### 5. 사례 4축 (다 있어야 PASS)
- [ ] 지역 + 업종 + 연차/매출 규모
- [ ] 감정 변화 (만남 → 컨설팅 중 → 결과)
- [ ] 박관장 개입 (구체 대화/조치)
- [ ] 결과 수치 (금액/기간/승인 단계)

### 6. 분량·구조
- [ ] 공백 제외 **1200~1300자** (벗어나면 FAIL)
- [ ] 3~4문장마다 줄나눔
- [ ] 본문 골격(S1~S3)이 `_variation-log` 직전 글과 다른가

### 7. SEO/GEO 최소선
- [ ] 메인키워드 12~15회(억지 반복 아님) / 서브키워드 7~10회
- [ ] GEO 정의문장 1개+ / 숫자 3개+ / "정리하면" 요약 / 핵심공식 1개
- [ ] 제목 30~38자 + 패턴번호(T1~T6) 명시

## 글자수 세는 법
공백 제외 글자수를 센다. 애매하면 도구로 확인:
```bash
python3 -c "import sys,re; t=open(sys.argv[1]).read(); print(len(re.sub(r'\s','',t)))" 파일.txt
```

## 산출물 형식

```
■ 종합 판정: 발행 가능 / 수정 필요 (FAIL N건)
■ 치명적 FAIL (있으면 무조건 수정)
   - [항목] 위반 문장: "___" → 수정안: ___
■ 일반 FAIL
   - [항목] 위치/문장 → 수정안
■ 통과 항목: NN / 전체 항목
■ 한 줄 코멘트: (가장 시급한 1가지)
```

## 원칙
- 점수만 매기지 말고 **위반 문장을 그대로 인용**하고 **고친 문장**까지 준다.
- 규칙끼리 충돌하면 v6.0 원칙대로 **자연스러움 > 규칙 충족**으로 판단한다.
