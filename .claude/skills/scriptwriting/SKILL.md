# 한비즈 유튜브 대본 작성 스킬 (완전체)

## 이 스킬은 무엇인가

박성제 대표 / 박현빈 대표가 직접 출연하는 유튜브 영상 대본을
**대표님 톤 그대로**, **시청자가 끝까지 보고 행동하게** 만드는 시스템.

## 가장 먼저 정할 것: 포맷과 무게

대본을 쓰기 전에 **두 가지 축**을 먼저 정한다. 이게 모든 톤 규칙을 좌우한다.

### 축 1 — 포맷: 인터뷰 vs 독백

이 채널은 **인터뷰**와 **독백** 두 포맷을 함께 운용한다. 둘은 톤과 장치가 다르다.

| | 인터뷰 포맷 | 독백 포맷 |
|---|---|---|
| 화자 | 대표 + 인터뷰어(A/백PD) | 대표 1인 정면 |
| 핵심 동력 | 티키타카, 케미, 리액션 | 차분하고 밀도 있는 진술 |
| 위트·농담 | 적극 활용 (잘 어울림) | 억지로 넣지 않음 (필요시 사용자가 추가) |
| 시청자 대리 | 인터뷰어가 질문·감정 대신 표현 | 대표의 자문자답으로 흡수 |
| 어울리는 주제 | 가벼운 정보, 사례 소개, 브로커 거르기 | 무겁고 진중한 사안, 생계·억울함·제도 비판 |
| BGM | 밝거나 경쾌 | 심각·진중 |

**포맷 선택 기준**: 주제가 가볍고 케미가 메시지를 도우면 인터뷰. 주제가 무겁고 케미가 메시지를 방해하면 독백. 애매하면 사용자에게 묻는다.

### 축 2 — 무게: 가벼운 유입형 vs 무거운 고위험형

| | 가벼운 유입형 | 무거운 고위험형 |
|---|---|---|
| 예시 주제 | 브로커 거르기, 정책자금 꿀팁, 마케팅 인사이트 | 생계·억울함, 법적 다툼, 돈이 직접 걸린 사안, 제도 비판 |
| 톤 | 날것, 케미, 강한 표현 허용 | 진중, 절제, 정확성 우선 |
| 강도 표현(D-1) | 적극 ("망합니다") | 절제 (과장보다 사실) |
| 위트·ㅋㅋ | 적극 | 최소화 또는 제거 |
| 팩트 검증 | 기본 확인 | **교차검증 필수** (PART L) |
| CTA | 최대 3회 | 2회 권장 (과하면 진정성 깎임) |

**무게가 톤을 이긴다.** 무거운 고위험형이면 인터뷰 포맷이라도 케미를 줄이고 진중하게 간다.

## 워크플로우 (반드시 이 순서로)

### STEP 1. 사용자 요청 받기

사용자가 다음 중 하나를 입력한다:
- 주제 + 포맷(인터뷰/독백) + 콘텐츠 유형(인터뷰/풀링/키/숏폼)
- 다른 유튜브 대본 + "이 구조로 우리 톤으로 바꿔줘"
- 실제 사례 정보 (클라이언트 케이스, 숫자, 결과)

### STEP 2. (필요시) 추가 정보 받기

다음이 빠져있으면 1~3개 질문으로 받는다:
- 어떤 회사 채널인지 (한비즈마케팅 vs 한국중소기업 비즈니스센터)
- **포맷 (인터뷰 vs 독백)** — 안 정해졌으면 주제 무게 보고 제안
- 콘텐츠 유형 (인터뷰/풀링/키/숏폼)
- 핵심 메시지 또는 사례 디테일
- 후킹 제목 방향

### STEP 3. 팩트 검증 (고위험 주제는 먼저)

무거운 고위험형이거나 구체 수치·제도·법령이 들어가면 **대본 작성 전에 교차검증**한다 (PART L). 검증 안 된 숫자·코드·단정은 대본에 넣지 않는다.

### STEP 4. 제목 후보 3개 + 대본 초안 작성

- 후킹 제목 3개 제시 (1개 추천)
- 대본 초안 (선택한 포맷·무게에 맞는 톤 규칙 적용)
- 인터뷰면 대화 형식, 독백이면 단일 화자 형식으로 출력

### STEP 5. 컨펌 받기

대본 끝에 항상 묻는다:
"이 대본 마음에 드시면 워드 파일 2종(디자인용/프롬프터용)으로 뽑아드릴까요? 수정 포인트 있으면 말씀해주세요."

### STEP 6. 수정 반영 (있을 경우)

사용자가 수정 요청하면 톤앤매너 규칙 다시 점검하며 반영.

### STEP 7. 컨펌 후 워드 2개 파일 자동 생성

컨펌 떨어지면 즉시 두 파일 생성 (PART I의 `scripts/` 생성 스크립트 사용):
1. `01_[주제]_디자인.docx` (인터뷰어/PD용)
2. `02_[주제]_프롬프터.docx` (촬영 프롬프터용)

# PART A. 콘텐츠 유형 정의

## A-1. 인터뷰 콘텐츠 (메인 포맷)

**목적**: 실제 사례 또는 정보 전달을 대화로 풀어 끝까지 보게 만든다.

**구조**: PART B-1 참조

**분량**: 5~9분

**용도**: 회사 유튜브 채널, 홈페이지 업로드

## A-2. 독백 콘텐츠 (진중형 메인 포맷)

**목적**: 무겁고 진중한 사안을 대표 1인의 밀도 있는 진술로 전달해, 공감과 신뢰를 만든다.

**구조**: PART B-2 참조

**분량**: 5~9분

**용도**: 제도 비판, 생계·억울함 사안, 진지한 정보 전달

## A-3. 풀링 콘텐츠

**목적**: 최대한 많은 사람을 끌어당긴다. "이 사람 뭔가 하는 사람이다"까지만 인식.

**특징**:
- 홍보 X, 상품/서비스 언급 X
- 관점, 사고방식, 문제 제기만
- 댓글, 저장, 공유 목표

**엔딩**: 철학적 질문, CTA 없음

**분량**: 5~7분 (1200~1500자)

## A-4. 키 콘텐츠

**목적**: 모인 사람 중 정확한 타겟만 골라낸다. "이거 나 얘긴데?" 자각.

**특징**:
- 홍보 가능 (단, 설명식 X)
- 불편해도 됨
- 걸러지는 사람 많을수록 성공

**엔딩**: 4단계 (타겟 지목 → 문제 재확인 → 해결 주체 포지셔닝 → 행동 요청)

**분량**: 5~7분 (1200~1500자)

## A-5. 숏폼

**목적**: 무조건 유입. 자극만 주고 끝.

**특징**: 홍보 X, 설명 X, 해결책 X. 문제만 던지고 끊는다.

**엔딩**: 미완성. "이거 모르면..." (끊김)

**분량**: 40초 이내 (150~200자)

# PART B-1. 인터뷰 대본 구조

> 인터뷰 포맷 전용. 독백이면 PART B-2로.

### 1단계: 바로 본론 진입 (오프닝 최소화)

**긴 오프닝은 이탈을 부른다.** 제목·썸네일 보고 들어온 시청자가 지루해하지 않게, 인사·자기소개 없이 바로 핵심 주제로 들어간다.

- 인사("안녕하세요"), 설명조 도입("오늘은 ~에 대해") 금지.
- 짧은 상황 제시나 한 줄 대화로 곧장 주제에 진입하는 건 좋다. 단, 길게 끌지 않는다.

좋은 예 (짧게 주제로 직행):
```
A: 관장님, 어제 상담받다 진짜 답답한 거 하나 봤어요.
대표: 뭔데요?
A: 신용취약자금인데, 정작 신용 취약한 사장님이 못 받는대요.
대표: 아... 그거. 저도 그 얘기만 들으면 속이 터집니다.
```

나쁜 예 (이탈 유발):
```
대표: 안녕하세요. 오늘은 정책자금에 대해 알려드리겠습니다. 먼저 제 소개를...
```

### 2단계: 두괄식 핵심 정보

영상 시작 1~2분 안에 시청자가 본 값을 했다고 느끼게 핵심 정보를 줘버린다.
"여기까지만 봐도 본 값 하셨어요"로 보상감 강조.

### 3단계: CTA #1 (보상 후 부탁)

핵심 정보 주고 나서 자연스럽게 구독 요청. 가벼운 유입형은 직설적으로("구독 누르면 돈 버시는 겁니다"), 진중형은 공론화 명분으로("목소리가 모여야 바뀝니다").

### 4단계: 본론 확장 (Why → How → What)

Why → How → What 순서로 풀어라. 각 항목에 **맥락에 맞는 비유**를 적절히 사용(과용 금지, PART D-2 참조).

### 5단계: 차별점 자연스럽게 깔기

회사 자랑은 인터뷰어(A)가 놀라는 형태로:
```
대표: 저희는 일단 돈 안 받고 시작합니다.
A: 네? 돈을 안 받아요?
대표: 네. 자금이 실행되기 전까지...
A: 그건 저희한테 너무 손해 아니에요?  ← 직원이 회사 걱정
대표: 손해죠. 그래서 저희도 아무나 안 받아요.  ← 자신감 있게 받음
```

### 6단계: CTA #2 (자존감 보상형)

```
여기까지 보고 계신 대표님이시면
진짜 정보 잘 챙기시는 분이세요.
```

### 7단계: 추가 가치 + (선택) 케미 농담

마케팅팀, 자금 후 매출 지원 등 추가 가치를 가볍게. 가벼운 유입형이면 인터뷰어 케미 농담을 끼운다. **위트는 어울릴 때만. 필수 아님.**

### 8단계: 마무리 CTA #3 + 액션

```
혼자 하실 수 있으시면 직접 하시는 게 제일 좋아요. 진심입니다.
근데 [상황 1], [상황 2], [상황 3] 이라면
저희한테 연락 한 번 주세요.
될 수 있는 건 확실하게 잡아드리고요.
안 되는 건 솔직하게 "안 됩니다" 라고 말씀드리겠습니다.
```

# PART B-2. 독백 대본 구조

> 독백 포맷 전용. 무겁고 진중한 사안에 쓴다. 대표 1인 정면, 심각한 BGM.

### 핵심 정서 흐름: 공감 → 공분 → 해결

독백의 뼈대는 이 3단이다. 반드시 이 순서로 간다.
1. **공감** — 시청자가 "내 얘기다" 하고 이입하도록 문제 상황에 충분히 머문다.
2. **공분** — 무엇이 부당한지 사실로 짚어 같이 분노하게 한다.
3. **해결** — 반드시 손에 잡히는 해결책을 **넘버링(1, 2, 3)**으로 준다.

**분노만 하고 끝내지 마라.** 공분만 사면 인사이트가 없고, 인사이트 없는 영상은 안 뜬다. 같이 분노한 뒤 최선의 해결책을 줘야 "이 채널 진짜 도움 된다" → 구독으로 이어진다.

### 1단계: 바로 본론 진입 (오프닝 없음)

썸네일 누르자마자 본 내용 시작. 인사·자기소개·긴 도입 전부 생략하고 첫 문장부터 주제를 던진다.

```
신용취약자금.
이름만 보면 신용 어려운 대표님 도우라고 만든 자금 같죠.
그런데 정작 도움이 필요한 대표님은
신청도 못 합니다.
```

### 2단계: 두괄식 핵심 정보

1~2분 안에 핵심을 줘버린다. "여기까지만 들으셔도 오늘 보신 값은 하십니다."

### 3단계: 공감 — 문제 상황에 머물기

시청자의 처지를 구체적으로 묘사한다. 빡친 썰 풀듯 짧게 끊어 던진다. 시청자 속마음을 대표가 대신 말해준다(자문자답):
```
"금액이 너무 커서 그런 거 아니야?" 싶으시죠.
근데 그것도 아니에요.
```

### 4단계: 공분 — 부당함을 사실로 짚기

감정적 비방이 아니라 사실로 분노를 유발한다. "이게 제도 취지에 맞는 겁니까?"처럼 시청자가 스스로 결론 내리게 한다.

### 5단계: CTA #1 (공론화 명분)

진중형 CTA는 구독을 "공론화의 힘"으로 연결한다:
```
이 구조가 잘못됐다 싶으시면 구독 한 번 눌러 주세요.
저 혼자 떠들면 푸념이지만, 같이 봐주시면 공론이 됩니다.
목소리가 모여야 바뀝니다.
```

### 6단계: 해결 — 넘버링으로 명확히

"화내는 걸로 끝나면 안 되잖아요"로 전환한 뒤, 해결책을 첫 번째·두 번째·세 번째로 또렷이 나눈다. 각 해결책마다:
- 시청자 반박을 자문자답으로 미리 받아친다 ("이것도 된다고? → 됩니다")
- 과장 없이 정확하게. 안 되는 건 안 된다고 솔직하게.

### 7단계: 행동 가이드

전화번호·사이트·신청처 등 시청자가 당장 따라 할 수 있는 실전 멘트를 준다. 모호한 통칭 대신 정확한 명칭으로.

### 8단계: 클로징 (감성 + CTA)

채널 정체성과 감성 소구로 닫되, **막연한 선의가 아니라 영상 주제와 한 몸으로 연결한다**(PART D-9). 진중형은 CTA 2회 권장.

# PART C. 화자 설정

## 대표 (박성제 CEO 또는 박현빈 CEO/COO)

- 직설적, 거침없음
- 본인 감정 표현은 날것 ("욱했어요", "속 터지더라고요", "이가 갈립니다")
- **간접 인용·전언투 금지.** "~라고 하더라고요", "~안 쓴다고 해요" 식으로 빼지 말고, 직접 겪고 확인한 것을 **자신감 있게 1인칭으로** 전한다. "제가 직접 통화해봤습니다", "제가 부딪혀 보니" — 전달자가 아니라 당사자의 목소리로.
- 고객 깎아내리지 않음 (단, 사기꾼/브로커는 신랄하게 비판 가능)
- 자조 위트 사용 가능 ("저희가 보험 팔 줄도 모릅니다") — **어울릴 때만, 필수 아님**
- 시청자한테 직접 화법 ("~하시는 대표님들")
- 본인 경험 솔직하게

## A (인터뷰어, 여성) — 인터뷰 포맷에서만

- 얼굴 노출 X (오프 보이스 또는 어깨 너머 실루엣)
- **단순 질문자가 아니라 회사 직원 캐릭터**
- 진짜 놀란 듯한 리액션 ("엥?", "와...", "진짜요?")
- 시청자 감정을 대신 표현
- 대표와의 케미 활용 (가벼운 유입형에서)

A의 대사는 다음 4가지 중 하나여야 한다:
1. **시청자 대리 질문** ("4가지가 뭔데요?")
2. **시청자 감정 대리** ("와 정부가 작정했네요")
3. **회사 직원으로서 놀람** ("그건 저희한테 손해 아니에요?")
4. **케미 농담 받아주기**

> 독백 포맷에서는 A가 없다. A의 역할(대리 질문·감정·반박)은 모두 대표의 자문자답으로 흡수한다.

# PART D. 톤앤매너 규칙

## D-0. 무게에 따른 톤 분기 (가장 우선)

- **가벼운 유입형**: 아래 규칙들을 적극 적용 (강한 표현, 케미, 날것 표기).
- **무거운 고위험형**: 진중·절제 우선. 강도 표현·ㅋㅋ·농담을 줄이거나 뺀다. **후킹은 살리되, 시청자가 불쾌하거나 싸구려로 느끼지 않게 품위를 지킨다.** 자극으로 후킹하지 말고 사안의 무게 자체로 후킹한다.

## D-1. 표현 강도 변환표

추상적 → 시각적, 약함 → 강함:

| 약함 | 강함 |
|---|---|
| 위험한 사람 | 뉴스 나올 사람 |
| 안 좋은 결과 | 빨간 줄 다이렉트로 그어짐 |
| 도움이 됩니다 | 돈 버시는 겁니다 |
| 사업이 어려워집니다 | 망합니다 |
| 의심스럽습니다 | 거짓말하는 거예요 |

**무거운 고위험형에서는 이 변환표를 절제한다.** 과장된 강도보다 정확한 사실이 신뢰를 만든다. "망합니다" 같은 단정은 가벼운 유입형에서만.

## D-2. 비유 사용 규칙

비유의 목적은 **이해도를 높이는 것**이지 비유 자체가 목적이 아니다.

- **대본당 맥락에 맞는 비유 최소 1개 유지.**
- **무맥락 은유 금지.** 갑자기 튀어나오는 억지 비유, 주제와 겉도는 비유는 쓰지 않는다.
- 자연스럽고 적절할 때만. 비유가 오히려 흐름을 해치면 차라리 직설로 간다.
- 좋은 예: "막아놓은 문 바로 옆에 다른 문을 열어둔 겁니다"(맥락 일치), "기록 한 줄에 기계가 도장 찍어버리는 구조"(상황 직결).
- 나쁜 예: 주제와 무관한 일상 비유를 장식처럼 삽입.

## D-3. 표기 규칙 (포맷·무게별)

- **가벼운 유입형 / 인터뷰**: ㅋㅋ, ????, !!!, "걍" 같은 줄임말, "엥?" "와..." 리액션, "(손 ㅂ2ㅂ2)" 액션 표기 적극.
- **무거운 고위험형 / 독백**: 위 표기 최소화 또는 제거. 과한 느낌표·고함체는 톤을 깬다. 멈춤은 `( … )`, 제스처는 `( 도장 찍는 제스처 )`처럼 담담하게.

## D-4. 문장 호흡

- 한 문장 15자 이내가 이상적, 20자 넘으면 끊어라.
- 마침표 많이. 짧게. 끊어서. 리듬감 있게.
- 독백은 한 호흡씩 줄바꿈해 낭독 리듬을 살린다.

## D-5. 궁금증 루프

```
궁금증 A 제시 → A 50%만 해결 → 전환("근데 더 열받는 게 있어요")
→ 궁금증 B → 50% 해결 → 전환 → 궁금증 C(클라이맥스) → 핵심 한 방
```

## D-6. 중간 이탈 방지 문장 (최소 1회, 남발 금지)

시청자를 붙드는 전환 문장을 **최소 1회 이상** 쓰되, **남발하지 않는다.** 매 단락마다 "여기서부터 중요해요"를 넣으면 흐름이 깨지고 노이즈가 된다. 꼭 필요한 클라이맥스 직전에만.

- 사용 가능: "근데 여기서 더 열받는 게 있어요", "이건 제가 직접 겪은 건데요"
- 주의: 같은 류 문장을 반복하지 말 것. 한두 번이면 리듬, 그 이상이면 군더더기.

## D-7. 절대 금지

- "안녕하세요"로 시작 / 긴 오프닝 (이탈 유발)
- "오늘은 ~에 대해 알려드리겠습니다" (설명조)
- "이제 ~를 설명하겠습니다" 류 메타 안내 남발
- 간접 인용·전언투로 자신감 없이 전달 ("~라고 하더라고요")
- 어려운 단어 그대로 ("제3자 부당개입 TF" → "전담팀")
- 검증 안 된 숫자·코드·단정 (PART L)
- 고객 비하 ("그분은 잘 모르셨어요", "버릇이었어요")
- 과시 ("저희가 최고입니다", "1등입니다")
- 이모지
- 따옴표 남용
- "여러분"/"당신" 호칭 (대신 "~하시는 대표님들")
- FOMO 표현 ("옆 가게가 먼저 하면 못한다")
- 무맥락 은유 (D-2)
- 무거운 주제에서 싸구려·불쾌하게 느껴지는 자극성 후킹

## D-8. 반드시 포함

**공통**
- 바로 본론 진입 (긴 오프닝 금지)
- 맥락에 맞는 비유 최소 1개
- 중간 이탈 방지 문장 최소 1회 (남발 금지)
- 마무리 행동 요청
- 모호함 제로 (PART D-10)

**인터뷰 포맷 추가**
- 인터뷰어 활용
- (가벼운 유입형이면) 케미 농담 — 어울릴 때만, 필수 아님

**독백 포맷 추가**
- 공감 → 공분 → 해결 3단 흐름
- 해결책 넘버링
- 시청자 반박 자문자답

## D-9. 감성 소구는 주제와 한 몸으로 (짜침 경계)

클로징 감성은 강력하지만, 막연한 선의("얼마나 많을까")로 가면 신파가 되고 싸 보인다. 감성도 영상의 핵심 주제와 직결돼야 진짜가 된다.

- 나쁜 예: "도움이 필요한 분들이 얼마나 많을까... 그래서 채널을 만들었어요" (붕 뜸)
- 좋은 예: "제도가 없는 게 아니라, 어디로 가야 하는지를 아무도 안 알려준 겁니다. 그래서 이 채널을 만들었어요" (주제와 결합)

## D-10. 모호함 제로 (이해도 점검)

쓴 사람은 맥락을 알지만 처음 보는 시청자는 한 군데만 막혀도 이탈한다. 출력 전 한 문장씩 점검:
- 지시대명사("이거", "그 상태")가 무엇을 가리키는지 명확한가?
- 통칭·줄임말이 실제 무엇인지 시청자가 아는가? (예: "채무조정 기반 재기 자금" 같은 임의 통칭 대신 실제 명칭)
- 주어가 누구인지 분명한가? (예: "심사 상태가 달라진다" → 누구의 상태인지)
- 전문용어는 **빼지 말고**, 정확히 박은 뒤 바로 쉽게 풀어준다 (전문성 + 이해도 동시 확보).

# PART E. 제목 & 썸네일 (세트로 설계)

## E-0. 제목과 썸네일은 역할을 나눈 세트다

제목과 썸네일이 같은 말을 반복하면 정보량이 절반으로 준다.
- **썸네일 = 감정**을 때린다 (예: "누굴 위한 정책자금입니까?")
- **제목 = 정보·검색**을 잡는다 (예: "막힌 자금 다시 받는 법 3가지")
- 둘이 역할을 분담하게 설계한다.

**제목은 반드시 내용과 일치한다.** 낚시 제목은 단기 클릭을 얻고 장기 신뢰를 잃는다. (예: 기록이 안 없어지는데 "없애는 법"이라 쓰면 안 됨 → "받는 법/푸는 법")

## E-1. 좋은 제목 패턴

1. **숫자 대비형**: "1년간 가맹점 1개 모집하던 본사, 한 달 만에 3개 계약"
2. **금기/비밀형**: "정책자금 브로커 10초 만에 거르는 법, 4가지만 외우세요"
3. **정체성 타격형**: "이 4가지 멘트 들으면 바로 끊으세요"
4. **반전 스토리형**: "망해가던 마사지샵이, 광고비 올리자고 했더니 욕하시던 원장님"
5. **상황+해결형(진중)**: "신용취약자금, 대위변제 500만원에 막혔습니다 | 다시 받는 법 3가지"

## E-2. 제목 조건

- 15~20자 이내 (모바일 잘림 주의)
- 다음 중 2개 이상: 숫자 / 금기·비밀 / 정체성 타격 / 강한 행동 지시
- 무거운 주제는 자극보다 사안+해결로 후킹

## E-3. 썸네일 가이드

- 2단 문구가 채널 공식. 핵심 단어만 색 대비(예: "못받습니다"만 빨강).
- 텍스트 덩어리는 하나를 주인공으로. 보조 문구(말풍선)는 작게.
- 표정은 주제 무게에 맞게. 무거운 주제는 과장된 분노보다 미간 좁힌 진중한 응시.
- 게시물 캡처 배경 사용 시: 작성자 신상 가리기, 핵심 한 줄만 키워 배경 처리. (재구성 시 실명·기관 비방 단정 금지)

## E-4. 나쁜 제목

- "마케팅 잘하는 법" (정보형, 감정 없음)
- "매출 올리는 방법" (포괄적)
- "사업 성공 비결" (클리셰)
- 내용과 안 맞는 낚시

# PART G. 표절 방지 (다른 유튜브 대본 참고 시)

사용자가 다른 유튜브 대본을 던져주고 "우리 톤으로 바꿔줘" 하면:

## 절대 하지 마라
- 원본 예시 그대로 사용
- 동일한 숫자, 순서, 비유
- 동일한 상황 설정 / 롤플레이 대사
- 원본 화자의 개인 경험 그대로

## 반드시 하라
1. 원본이 왜 잘 됐는지 **구조**만 추출
2. 핵심 인사이트를 **맥락에 맞는 새 비유**로 재해석
3. 예시는 **다른 산업/상황**으로 치환
4. 숫자는 다른 체계 사용
5. 롤플레이는 완전히 새로운 상황으로

## 기준
"영감 받았다고는 할 수 있지만, 베꼈다고는 절대 말할 수 없는 콘텐츠"

# PART I. 워드 파일 생성 (컨펌 후)

사용자 컨펌 떨어지면 즉시 두 파일 생성. **이 스킬의 `scripts/` 폴더에 생성 스크립트 2종이 들어있다.** 직접 docx 코드를 새로 짜지 말고 이 스크립트를 쓴다.

## I-0. 생성 절차

1. 대본을 **JSON 데이터 파일**로 만든다 (구조는 I-3 참조).
2. 작업 폴더에 docx 라이브러리가 없으면 설치: `npm install docx` (또는 전역 설치본 사용).
3. 두 스크립트를 실행한다:

```bash
node scripts/make_design_doc.js <script.json> 01_[주제키워드]_디자인.docx
node scripts/make_prompter_doc.js <script.json> 02_[주제키워드]_프롬프터.docx
```

4. 생성 후 `python /mnt/skills/public/docx/scripts/office/validate.py`로 검증.
5. `present_files`로 두 파일 출력.

> 같은 JSON 하나로 디자인용·프롬프터용이 동시에 나온다. 대본 내용은 JSON에만 담고, 디자인은 스크립트가 알아서 입힌다.

## I-1. 디자인 워드 (`make_design_doc.js`)

인터뷰어/PD용. 네이비(#1A2332)+골드(#C9A961)+베이지(#F5F3EE) 톤, 헤더/푸터, 제목+부제, 촬영 구성/핵심 강조점 2단 박스, 블록별 색 구분.

- 대표 멘트/대사(`ment`/`rep`) = 베이지 박스(골드 좌측 바)
- 인터뷰어 A(`interviewer`) = 흰 배경 + 회색 바 + 라벨
- 시청자 속마음(`viewer`) = 흰 배경 + 빨강 텍스트(빨강 바)
- 핵심 콜아웃(`callout`) = 네이비 테두리 박스
- CTA(`cta`) = 골드 박스
- 지문(`direction`) = 회색 이탤릭 가운데
- 섹션(`section`) = 네이비 바
- 전화번호(`phones`) = 네이비 헤더 + 베이지 강조 테이블

## I-2. 프롬프터 워드 (`make_prompter_doc.js`)

촬영용. 흰 배경·검정 텍스트, 디자인 없음.

- 대표 대사 = 18pt 큰 글씨, 한 호흡씩 줄바꿈, 같은 멘트 내 빈 줄 없음
- 인터뷰어 A 큐 = 작은 회색 이탤릭 + [A], 위 공백 600/아래 480
- 시청자 속마음 = 작은 회색 이탤릭 + [시청자 속마음]
- CTA = 금색 굵은 글씨 구분선 + 위 공백
- 지문 = 회색 이탤릭 가운데 / 섹션 = 작은 네이비 큐 / 전화번호 = 큰 글씨

## I-3. JSON 데이터 구조

두 스크립트가 공유하는 입력 형식. `format`은 `"interview"` 또는 `"monologue"`.

```json
{
  "format": "monologue",
  "company": "한국중소기업 비즈니스센터",
  "footer": "한국중소기업 비즈니스센터  ·  누적 승인 5,657건  ·  승인률 97.2%  ·  수임료 0원 성공보수제",
  "title": "제목",
  "subtitle": "부제 (선택)",
  "shooting": ["촬영 구성 줄1", "줄2"],
  "highlights": ["핵심 강조점 줄1", "줄2"],
  "blocks": [
    { "type": "section", "text": "1. 섹션 제목" },
    { "type": "ment", "lines": ["대표 멘트 줄1", "", "빈 문자열은 한 줄 띄움"] },
    { "type": "viewer", "text": "시청자 속마음 한 줄 (독백)" },
    { "type": "rep", "lines": ["대표 대사 (인터뷰)"] },
    { "type": "interviewer", "lines": ["A 대사 (인터뷰)"] },
    { "type": "callout", "lines": ["핵심 강조 멘트"] },
    { "type": "direction", "text": "도장 찍는 제스처" },
    { "type": "phones", "items": [ {"name":"신용회복위원회","value":"1600-5500"} ] },
    { "type": "cta", "label": "[ CTA #1 — 공론화 ]", "lines": ["..."] }
  ]
}
```

**블록 타입 요약**: `section`(섹션 구분), `ment`/`rep`(대표 멘트·대사), `interviewer`(A, 인터뷰 전용), `viewer`(시청자 속마음, 독백 전용), `callout`(핵심 강조), `cta`(구독 유도), `direction`(지문), `phones`(전화번호 표), `spacer`(여백).

- 독백이면 `ment`·`viewer` 중심으로, 인터뷰면 `rep`·`interviewer` 중심으로 블록을 구성한다.
- `lines` 배열의 빈 문자열 `""`은 의미 블록 사이 한 줄 띄움으로 렌더된다.

# PART L. 팩트 정확성 & 교차검증 (고위험 주제 필수)

정보형·고위험 콘텐츠는 틀린 사실 하나가 채널 전체 신뢰를 무너뜨린다. 시청자가 이걸 믿고 실제로 전화하고 움직인다.

## L-1. 원칙
- **단정은 책임이다.** 책임질 수 없으면 표현을 낮춘다. ("신청 가능합니다" → "신청되는 경우가 있습니다")
- **출처 불확실한 숫자·코드는 뺀다.** 검증해서 근거 없으면 빼는 게 이기는 거다. (예: "코드 139"는 공식 규약에서 미확인 → 삭제)
- **공고·제도는 시점 의존적.** 매년 갱신되는 자금은 "신청 전 최신 공고 확인" 안내를 넣는다.
- **임의 통칭 금지.** 실제 명칭으로. (상담 가서 그대로 말해도 통하게)

## L-2. 검증 절차
1. 구체 수치·제도·법령·코드가 들어가면 작성 전 공식 출처로 확인 (소진공/신용정보원/기금 공식 사이트, 공고 원문).
2. 카페·커뮤니티에서 나온 표현은 그대로 옮기지 말고 공식 출처로 교차 확인.
3. 확인 안 되면: 빼거나, "현장에서 흔히 ~라고 부르는" 식으로 단정을 한 단계 낮춘다.
4. 검증된 사실만 자신감 있게, 검증 안 된 건 톤을 내린다.

## L-3. 검증 우선 대상
- 금액·비율·건수·기한 등 모든 숫자
- 제도·자금·법령의 적용 조건과 예외
- 신용정보 코드·등록/해제 규칙
- "된다/안 된다"를 가르는 자격 요건
