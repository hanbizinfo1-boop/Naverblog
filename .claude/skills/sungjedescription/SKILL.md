# Sungje Description — 성제관 유튜브 롱폼 설명란 작성 스킬

## 이 스킬은 무엇인가

성제관(한국중소기업 비즈니스센터) 유튜브 롱폼 영상의 설명란을 작성하는 전용 스킬.

쇼츠 설명글이 아님. 일반 영상(롱폼) 본 영상 하단에 들어가는 설명란이다.

**4단 구조 고정**:
1. 해시태그 (최대 4개)
2. 설명글
3. 타임라인
4. CTA (행동 유도 멘트 + 링크)

---

## 핵심 신념

- 타임라인은 목차가 아니라 후킹이다. 시청자가 눌러보고 싶게 만들어야 한다.
- 설명글은 영상 요약이 아니라 핵심을 짚는 SEO 미끼다. 너무 자세히 쓰면 시청자가 영상을 안 본다. 그러나 시청자가 내용을 명확히 이해할 수 있도록 돕는다는 본질은 잊지 않는다.
- AI가 쓴 티를 절대 내지 않는다. 마크다운 강조·이모지 과다·기계적인 문장 전부 금지.
- 메인 키워드는 검색엔진에 잡혀야 한다. 설명글 안에 자연스럽게 1~2회 박는다.
- CTA의 행동 유도 멘트는 영상 주제에 맞게 매번 다르게 쓴다. 링크만 고정.

---

## 워크플로우

### STEP 1. 입력 받기

사용자가 설명란을 요청하면 다음을 확인한다:

- **영상 대본** (필수) — 자막·대본 전체
- **메인 키워드** (필수) — SEO 타겟 키워드 (예: 재도전특별자금, 고유가피해지원금, 정책자금 거절 등)
- 채널: 기본값 성제관 / 한국중소기업 비즈니스센터
- CTA 링크: 기본값 https://www.krbizinfo.co.kr/

메인 키워드를 사용자가 안 줬으면 대본 보고 추정해서 "메인 키워드는 ㅇㅇㅇ로 잡으면 될까요?" 한 번만 확인.

### STEP 2. 대본 통독 후 추출

타임라인 짜기 전에 대본을 처음부터 끝까지 읽고 다음을 뽑는다:

1. **장면 분할** — 대본의 흐름이 바뀌는 지점 7~12개
2. **각 장면의 후킹 포인트** — 그 구간에서 가장 궁금증·반전·실용성을 자극하는 한 문장
3. **핵심 요약 3~5줄용 메시지** — 영상이 시청자에게 결국 뭘 말하는지
4. **CTA 행동 유도 멘트용 키워드** — 영상 주제에 맞는 동사·명사 (확인하기 / 상담받기 / 신청법 보기 / 정답 찾기 등)
5. **해시태그 후보 20개** — 영상 키워드 + 확장 키워드 (유입 가능성 있는 유의미 키워드)

### STEP 3. 4단 구조로 작성

PART A~D 규칙대로 작성.

### STEP 4. 출력 전 검증

PART E 체크리스트 전부 통과해야 출력. 하나라도 걸리면 재작성.

## PART A. 해시태그 작성 규칙

### A-1. 개수

- **최대 4개**
- 3~4개 사이 권장 (과도한 개수 대신 핵심 키워드에 집중)

### A-2. 구성 비율

| 계층 | 내용 |
|---|---|---|
| 계층 1 — 메인 키워드 | 영상의 메인 SEO 타겟 키워드 |
| 계층 2 — 영상 내 호명 키워드 | 대본에 실제 등장한 구체 키워드 |


### A-3. 작성 규칙

- 띄어쓰기 없이 한 줄 또는 두 줄로 붙여 쓰기
- 해시태그 사이 공백 한 칸씩
- 영문 키워드 가능 (예: `#K-팝업` `#MZ창업`)
- 연도·분기 키워드 적극 활용 (`#2026정책자금` `#2분기소상공인자금`)
- 도배 금지 (`#정책자금` `#정책자금대출` `#정책자금신청`까지는 OK, 그 이상 반복은 감점)

### A-4. 금지

- 영상과 무관한 인기 태그 (`#일상` `#vlog` 등)
- 의미 없는 일반화 (`#사업` `#돈` 같은 대분류만 단독으로)

---

## PART B. 설명글 작성 규칙

### B-1. 분량

- **3~6줄 단문 블록** 1~2개
- 절대 길게 쓰지 말 것. 영상을 대체해선 안 된다.

### B-2. 내용 구조

타입 1 — 감상·코멘트형 (가벼운 주제):
- 영상 주제를 한 문장으로 짚기
- 가벼운 감정 표현 (재밌네요 / 황당하네요 / 안타깝네요)
- 누구를 위한 영상인지 + 응원 한 줄

타입 2 — 본문 미리보기형 (정보·노하우 주제):
- 핵심 결론을 미리 던지기 (대본의 가장 강한 단정문)
- 의문 제기 ("이거 사기 같죠?")
- 영상이 어떤 답을 주는지 짧게 암시
- "자세한 내용은 영상으로 확인하세요" 류로 마감

### B-3. 메인 키워드 SEO 처리

- 메인 키워드는 설명글 본문에 **1~2회 자연스럽게** 등장
- 첫 문장이나 마지막 문장에 한 번은 박는 것을 권장
- 키워드 도배 금지 (3회 이상 반복하면 어색해짐)
- 변형형도 활용 가능 (예: 메인이 `정책자금`이면 `정책자금 대출`, `정책자금 신청` 등도 함께)

### B-4. AI 티 제거 규칙

**절대 금지**:
- 마크다운 강조 (`**볼드**`, `*이탤릭*`, `# 헤더`)
- 이모지 과다 사용 (영상 주제와 무관한 장식 이모지)
- 기계적 나열 ("첫째, 둘째, 셋째" 식 정리)
- "이 영상에서는 ~을 다룹니다" 식 메타 설명
- 영문 대시 `—` 남발 (자연스러우면 1개 OK)

**허용**:
- 짧은 감정 이모지 1~2개 (`:)`, `..?`, `(?)` 같은 자연스러운 표현)
- 줄임표 `..` 또는 `...` (자연스러운 호흡용)
- 물음표·느낌표 적당히 (전체 글에서 각 1~2개)

### B-5. 톤앤매너 (성제관 / 박관장 톤)

- 어미: `~입니다 / ~거든요 / ~더라고요 / ~겁니다`
- 존댓말 기반
- 한 문장 30자 이내 권장
- 자영업자·소상공인 응원 톤
- "박관장의 컨설팅" 같은 페르소나 호명 허용

## PART C. 타임라인 작성 규칙

### C-1. 분량

- 7~12개 항목
- 영상 길이에 비례 (5분 영상이면 7개, 10분 영상이면 10~12개)
- 너무 잘게 쪼개지 말 것. 시청자가 스크롤하다가 지친다.

### C-2. 시간 표기

- `MM:SS` 또는 `M:SS` 형식 (예: `00:34`, `2:07`)
- 1시간 넘으면 `H:MM:SS`
- 영상 첫 타임라인은 항상 `00:00`

### C-3. 후킹 작성 규칙

**핵심: 목차가 아니라 클릭 유도 카피.**

좋은 예 vs 나쁜 예:

| 나쁜 예 (목차형) | 좋은 예 (후킹형) |
|---|---|
| 정책자금 소개 | 정부가 말 바꿨습니다 |
| 신청 자격 설명 | 무주택자도 탈락하는 이유 |
| 서류 준비 방법 | 부결 사유 4️⃣ 사업계획서가 엉망 |
| 마무리 정리 | 포기만 안 하면 됩니다 |

**작성 원칙**:
- 한 줄에 들어가는 후킹은 25자 이내
- 숫자·반전·궁금증·구체 명사 중 1개 이상 포함
- 질문형 가능, 단정형 가능, 둘 다 섞어도 됨
- 영상에서 실제 다루는 내용을 반영 (낚시 금지)
- 첫 항목(00:00)은 영상 전체를 0.5초 안에 자리에 앉히는 강한 단정문

**번호·기호 사용**:
- 핵심 단계·사유 나열할 때 `1️⃣ 2️⃣ 3️⃣ 4️⃣` 같은 키캡 이모지는 허용 (이건 정보 구조용이라 OK)
- 그 외 장식 이모지(🔥 ✨ 💡 등)는 금지
- `→` 화살표는 허용 (변화 표현용)

### C-4. 타임라인 출력 포맷

```
00:00 [첫 후킹]
00:34 [두 번째 후킹]
01:39 [세 번째 후킹]
...
```

시간과 후킹 사이는 공백 한 칸. 줄당 하나의 항목.

## PART D. CTA 작성 규칙

### D-1. 고정 구조

```
[영상 주제 맞춤 한 줄 코멘트 또는 안내] (선택)

[👇 행동 유도 멘트]
[기관/링크 안내 한 줄] (선택, 외부 공식 링크 있을 때만)
[공식 링크 URL] (있을 때만)

[👇 박관장/성제관 컨설팅 유도 멘트]
https://www.krbizinfo.co.kr/
```

### D-2. 행동 유도 멘트 작성 원칙

영상 주제에 따라 매번 다르게 쓴다. 동사+대상 조합.

**예시 패턴**:

| 영상 주제 | 행동 유도 멘트 |
|---|---|
| 신용 낮아도 받을 수 있는 자금 | 👇내 신용점수에 맞는 정책자금 확인하기 |
| 고유가피해지원금 조건 | 👇고유가피해지원금 상담 받기 |
| 정책자금 거절 사유 | 👇링크 눌러 정답 찾기 |
| 재도전특별자금 신청법 | 👇재도전특별자금 신청 자격 확인하기 |
| 보증서 대출 | 👇내 사업장 보증한도 진단받기 |
| 대환대출 | 👇기대출 한도 점검 받기 |

**규칙**:
- 👇 이모지는 행동 유도 멘트 앞에 고정 사용
- 멘트 길이 25자 이내
- 동사로 끝내기 (확인하기 / 상담받기 / 진단받기 / 점검받기 / 찾기 / 보기)
- 영상 메인 키워드를 멘트 안에 포함시키면 가장 강함

### D-3. 외부 공식 링크 처리

영상에서 정부 기관 공식 페이지를 언급하면, 박관장 컨설팅 링크 위에 별도 블록으로 안내:

```
👇 이의제기와 자금 확인 모두 아래에서 가능합니다.

국민신문고 홈페이지👇
고유가 피해지원금 이의제기 신청서
https://www.epeople.go.kr/nsf/Intro.html

박관장의 컨설팅이 필요하시다면?👇
https://www.krbizinfo.co.kr/
```

외부 공식 링크가 영상에 안 나오면 박관장 링크 한 블록만.

### D-4. 박관장 컨설팅 링크 (고정)

```
👇[영상 주제 맞춤 멘트]
https://www.krbizinfo.co.kr/
```

또는 박관장 페르소나 강조 시:

```
박관장의 컨설팅이 필요하시다면?👇
https://www.krbizinfo.co.kr/
```

영상 흐름에 따라 둘 중 선택.

## PART E. 출력 전 검증 체크리스트

설명란 출력 직전에 이 항목들 전부 통과해야 한다. 하나라도 NO면 재작성.

**[구조 점검]**
- [ ] 4단 구조 순서가 맞는가 (해시태그 → 설명글 → 타임라인 → CTA)
- [ ] 타임라인이 7~12개인가
- [ ] 첫 타임라인이 `00:00`인가
- [ ] 설명글이 1~2개 단문 블록인가 (너무 길지 않은가)
- [ ] CTA가 행동 유도 멘트 + 링크 구조인가

**[해시태그 점검]**
- [ ] 최대 4개 이하인가
- [ ] 메인 키워드와 핵심 키워드만 들어갔는가
- [ ] 영상과 무관한 태그 없는가

**[설명글 점검]**
- [ ] 메인 키워드가 1~2회 자연스럽게 들어갔는가
- [ ] 마크다운 강조 없는가
- [ ] 이모지 과다 사용 없는가
- [ ] 영상 내용을 너무 자세히 쓰지 않았는가
- [ ] AI 티 나는 문장 없는가 ("이 영상에서는~" 같은)

**[타임라인 점검]**
- [ ] 후킹이 목차가 아니라 클릭 유도형인가
- [ ] 후킹 한 줄당 25자 이내인가
- [ ] 영상에 실제 나오는 내용인가 (낚시 없는가)

**[CTA 점검]**
- [ ] 행동 유도 멘트가 영상 주제에 맞는가 (고정 멘트 복붙 X)
- [ ] 👇 이모지가 행동 유도 멘트 앞에 있는가
- [ ] 링크 URL이 정확한가 (https://www.krbizinfo.co.kr/)
- [ ] 영상에 정부 공식 사이트 언급되면 별도 안내 블록 추가됐는가

## PART F. 출력 포맷

해설·설명 일체 금지. 바로 복붙 가능한 설명란 본문만 출력.

```
[해시태그 한 줄]

[설명글 단문 블록]

[타임라인 7~12줄]

[CTA 블록]

```

블록 사이는 빈 줄로 구분.

## PART G. 출력 예시 (참조용)

### 예시 1 — 매출 100원이어도 기술보증기금 정책자금으로 1억 받은 사례 소개 영상

```
#기술보증기금  #2026정책자금 #제조업창업  #제조업정책자금
```
