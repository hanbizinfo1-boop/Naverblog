# 네이버 이미지 샷리스트 (naver-image-shotlist)

> ⚠️ **전제가 바뀌었다.** 이제 이미지 파일을 실제로 조달해 폴더에 넣는다.
> 조달 경로·허용 출처·파일명 규칙의 주인은 `templates/작성-운영규칙.md` 다.
> 컷 수·비율·배치 위치의 주인은 그 글의 `templates/템플릿-0N-*.md` 다.
> **이 스킬의 역할은 그중 "직접 촬영이 가능한 컷"을 골라 구도를 설계하는 것**으로 좁힌다.

네이버는 **직접 촬영 고화질 실사진에 가산점**, 퍼온 스톡 이미지에 감점을 준다.
스톡으로 채운 컷이라도 대표님이 직접 찍을 수 있는 것이라면 촬영안을 제시해
교체를 권한다. 특히 **대표 이미지와 사례 장면**은 직접 촬영본의 효과가 크다.

## 입력
- 완성된(또는 골격이 잡힌) 블로그 글 — `(사진N)` 자리 포함

## 처리
글의 각 이미지 자리마다 아래 4가지를 만든다.

1. **직접 촬영안 (1순위)** — 무엇을, 어떤 구도로
   - 예: 상담 현장 책상 위 서류와 펜, 위에서 내려다본 구도 (손만 살짝 나오게)
2. **대체 무료출처안 (촬영 어려울 때)** — 저작권 안전 사이트 + 검색어
   - 사이트: 공유마당(gongu.copyright.or.kr) / Pexels / Pixabay / Unsplash / 네이버 OGQ마켓
   - 검색어: "정부지원 서류" "상담 미팅" 등
3. **캡션 문구** — 박관장 톤의 짧은 사진 설명 (인용부호·이모지 없이)
4. **대체텍스트(alt) 키워드** — 메인/서브 키워드 자연 포함

## 이미지 구성 원칙 (네이버 SEO)
- 글당 컷 수는 **템플릿이 정한다** (`templates/템플릿-0N-*.md`). 여기서 정하지 않는다
- 직접 촬영 비중이 높을수록 유리. 스톡 비중 70% 초과 시 교체 권장 컷을 지목한다
- **첫 이미지(대표)**가 클릭을 좌우 → 가장 공들인다
- 같은 사진 반복·무료 스톡 도배 금지(감점)
- 가능하면 **15초+ 동영상 1개** 자리도 제안(가산점)
- 텍스트 박힌 이미지(인포그래픽 1~2장)는 체류시간에 도움

## 정책자금 글 특화 촬영 소재 예시
- 상담 현장(책상, 서류, 노트북 화면 일부)
- 손글씨 메모/체크리스트
- 사무실 외관·간판(신뢰도)
- 박관장 본인 컷(IP화 — 얼굴 노출 가능하면 강력)
- 숫자 강조용 화이트보드/메모

## 산출물 형식

```
■ 이미지 샷리스트 (총 N컷 + 동영상 N개)

(사진1) · 대표
 - 직접촬영: ___ (구도: ___)
 - 대체: 사이트 ___ / 검색어 "___"
 - 캡션: ___
 - alt: ___

(사진2)
 ...

[동영상 1] (선택)
 - 15초+ : ___ 장면

■ 촬영 체크: 직접촬영 N컷 / 대체 N컷
■ 한 줄 팁: 대표 이미지에 ___를 넣으면 클릭률↑
```

## 주의 (정직하게)
- 무료 사이트라도 **상업적 사용·인물 초상권** 조건을 한 번 확인하라고 안내한다.
- AI 생성 이미지를 원하면 별도 도구로 만들 수 있으나, 네이버는 실사진을 더 우대한다는 점을 알린다.
