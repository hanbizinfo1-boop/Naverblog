# Sungje Shorts — 쇼츠 설명글 퍼널 작성 스킬

## 이 스킬은 무엇인가

유튜브 쇼츠·인스타 릴스·틱톡에 공통으로 업로드할 설명글을 작성하는 전용 스킬.

단 하나의 목적: 읽는 사람이 홈페이지를 클릭하게 만드는 것.

본 영상 유입용이 아니다. 쇼츠를 본 사람이 설명글을 읽은 그 순간, "내 상황이 어떤지 확인해봐야겠다"는 행동 욕구가 발생해서 그 자리에서 유튜브에 성제관 채널을 검색해보고, 프로필 링크를 눌러 찾아보게 만드는 게 목표.

---

## 핵심 신념

- 설명글은 장식이 아니라 퍼널이다. 모든 문장이 CTA를 향해 있어야 한다.
- 본 영상 유도 금지. "전체 영상 보러가기" 같은 문구는 퍼널을 반으로 쪼갠다. 쇼츠 한 편이 완결된 퍼널이어야 한다.
- 정보를 주면 안 된다. 자가 진단 욕구를 줘야 한다. 답을 주면 클릭 안 한다. "내 상황은 어느 쪽이지?"를 만들어야 클릭한다.
- 첫 줄에서 독자를 자리에 앉힌다. 훅이 약하면 나머지 4단이 무의미.

---

## 워크플로우

### STEP 1. 요청 받으면 확인

사용자가 설명글을 요청하면 다음을 받는다:

- 쇼츠 대본 / 자막 (필수) — 실제 쇼츠에 들어가는 텍스트 전체
- 롱폼 원본 대본 (선택, 있으면 더 정확) — 쇼츠가 롱폼에서 쪼개진 경우
- CTA (기본값: 뒷 이야기가 궁금하다면 유튜브 '성제관' 검색 해보시거나 프로필 고정링크를 확인해보세요!)
- 채널/브랜드 (기본값: 성제관 / 한국중소기업 비즈니스센터)

### STEP 2. 대본에서 5가지 추출

설명글 쓰기 전 반드시 대본을 실제로 읽고 뽑는다. 추정·일반론 금지.

1. 가장 강한 단정문 1개 (훅용)
2. 타겟의 현재 상황 리스크 1개 (불안 증폭용)
3. 대본 주제에 맞는 CTA 동사 (확인 / 진단 / 검토 / 점검)
4. 핵심 주제어 2개 (해시태그 계층 1용) — 대본에서 실제 호명된 것만
5. 타겟·업종 1개 (해시태그 계층 2용) — 대본에서 호명된 타겟만

중요: 대본에 없는 개념은 넣지 말 것. 대본이 "소진공 대출" 얘기면 CTA도 소진공 맥락, 해시태그도 소진공 계열이다. 임의로 "중진공" 갖다 붙이면 안 됨. 대본이 "IR 자료" 얘기면 해시태그에 `#정책자금` 넣지 말 것.

### STEP 3. 퍼널 구조로 작성

PART A 퍼널 설계 원칙대로 4단 구조로 작성.

### STEP 4. 출력 전 검증

PART D 검증 체크리스트 전부 통과해야 출력. 하나라도 걸리면 재작성.

## PART A. CTA 퍼널 설계 원칙

설명글 전체가 하나의 퍼널이다. 4단계로 독자를 링크 클릭까지 끌고 간다.

### 1단 — 인지 충격 (첫 줄)

독자의 반응: "어? 이거 내 얘기인가?"

- 대본에서 가장 강한 단정문 1개를 첫 줄에 박음
- 타겟이 0.5초 안에 "내 얘기네" 느끼게
- 숫자·업종·기간 등 구체 앵커 1개 이상 포함
- 질문형 금지, 단정형만
- 25자 이내

좋은 예:
- 정책자금은 신청 순서 1개로 승인 여부가 갈립니다.
- 은행부터 돌고 계신 대표님들, 99%가 순서가 틀렸습니다.

나쁜 예:
- 정책자금에 대해 알고 계신가요? (질문형 금지)
- 정책자금은 중요합니다. (구체 앵커 없음)

### 2단 — 불안 증폭 (2~3줄)

독자의 반응: "지금 내 상황이 이거면 어떡하지?"

- 1단의 훅을 독자 본인의 리스크로 번역
- "지금 ~하고 계시면 ~입니다" 구조로 독자를 자리에 앉힘
- 핵심 정보는 흘리되, **본인 상황은 "확인해봐야 알 수 있음"** 으로 남김
- 꼬리는 본 영상이 아니라 CTA 쪽으로 빠져야 함
- "근데 진짜 문제는" / "여기서 대부분 갈립니다" 같은 전환 활용

좋은 예:
> 지금 은행부터 돌고 계신 대표님들, 순서 거꾸로 가고 계시는 겁니다.
> 이 순서 모르고 신청하면 신용만 떨어지고 끝나거든요.
> 대표님 상황이 어느 쪽인지는 직접 확인해봐야 정확합니다.

마지막 줄이 핵심. "직접 확인해봐야"가 3단으로 넘어가는 다리.

### 3단 — 자가 진단 욕구 → 행동 지시

독자의 반응: "확인이라도 해봐야겠네."

CTA 문장을 대본 주제에 맞춰 직접 추출:

| 대본 주제 | CTA 동사 | 예시 문장 |
|---|---|---|
| 자금 승인·한도 | 확인 | 받을 수 있는 자금이 있는지 확인해보세요 |
| 사기 경고·업체 검증 | 검토 | 정상 업체인지 먼저 검토받아보세요 |
| 승인율·업종 적합 | 진단 | 대표님 업종이 승인 가능한지 진단받아보세요 |
| 서류·순서 | 점검 | 지금 준비 중인 서류 점검부터 받아보세요 |

단어 규칙:
- "상담 신청하세요" 같은 무거운 단어 금지 → 확인 / 진단 / 검토 / 점검으로
- 무료 느낌은 은근히 (직접 "무료"라고 쓰진 말 것)
- 구체적 입력 요소 명시하면 신뢰도 ↑ ("업종·매출·기대출 넣으면")

좋은 예:
> 업종·매출·기대출 넣으면 받을 수 있는 자금 바로 확인됩니다.

### 4단 — CTA 멘트

```
뒷 이야기가 궁금하다면
유튜브 '성제관' 검색 해보시거나
프로필 고정링크를 확인해보세요!
```

링크 앞뒤에 아무것도 붙이지 않음. 한 줄 단독.

### 5단 — 해시태그 5개 (쇼츠 대본 맥락에서 추출)

해시태그는 쇼츠 대본을 실제로 읽고 거기서 추출한다. **총 5개**, 마지막 2개 고정.

3계층 구성:

**계층 1 — 핵심 주제어 (2개)**

대본의 본론이 실제 다루는 구체 키워드.

- 예: 소진공 대출 얘기 → `#소진공대출 #소상공인자금`
- 예: 사기 업체 경고 → `#정책자금브로커 #컨설팅사기`
- 예: 신용보증 얘기 → `#신용보증기금 #보증서대출`
- 예: IR·투자 유치 얘기 → `#IR자료 #투자유치`

**계층 2 — 타겟·업종 (1개)**

대본에서 호명한 타겟만. 일반화 금지.

- 창업자 주제 → `#예비창업자` 또는 `#창업자금`
- 자영업자 주제 → `#소상공인` 또는 `#자영업자`
- 중소기업 주제 → `#중소기업자금`
- 채무조정 주제 → `#저신용사업자대출`

**계층 3 — 브랜드 고정 (2개)**

마지막 2개는 항상 동일:
`#성제관 #한국중소기업비즈니스센터`

**합산 규칙**
- 계층 1 (2개) + 계층 2 (1개) + 계층 3 (2개) = 총 5개
- 대본에 없는 개념의 태그는 넣지 말 것 (예: 대본이 소진공 얘긴데 `#중진공` 박으면 알고리즘 감점)
- 띄어쓰기 없이 한 줄로 붙여 쓰기

**금지**
- 맥락 무관한 인기 태그 끌어오기 (`#일상` `#사업` 같은 대분류)
- 브랜드 해시태그 도배 (계층 3 외 추가 금지)

## PART B. 톤앤매너

### B-1. 박성제 대표 톤 (성제관 채널)

- 어미: `~이겁니다 / ~거든요 / ~더라고요 / ~해야겠죠`
- 존댓말 기반
- 한 문장 25자 이내 (술술 읽히게)
- 문단 사이 빈 줄 1줄씩

### B-2. 박현빈 대표 톤 (한비즈마케팅)

- 어미: `~습니다 / ~이에요 / ~거든요`
- 직설적, 자기 경험 기반
- 한 문장 25자 이내

## PART C. 절대 금지 사항

### C-1. 무거운 CTA 단어 금지

- "상담 신청하세요" ❌
- "지금 바로 문의" ❌
- "1:1 상담 예약" ❌

→ 진입 장벽 느껴짐. 확인 / 진단 / 검토 / 점검으로.

### C-2. 톤 금지

- 이모지 일체 금지 (✓, ▶, 🔥 모두 포함)
- 느낌표·물음표 남발 금지 (전체 글에서 느낌표는 최대 1개)
- "여러분", "안녕하세요", "반갑습니다" 금지
- "구독 부탁드립니다", "좋아요 눌러주세요" 금지
- "꿀팁 대방출", "충격", "대박" 단독 사용 금지

### C-3. FOMO 조건부 금지

한비즈마케팅 광고 규칙에 따라 다음 표현 금지:
- "딱 N명 한정"
- "마감 임박"
- "같은 동네 1곳만"
- "옆 가게가 먼저 하면"

→ 대신 자가 진단 욕구로 행동 유도.

### C-4. 의료적·법적 단정 금지

- "100% 승인됩니다" ❌
- "무조건 받을 수 있습니다" ❌

→ "확인 가능합니다" / "가능성 있습니다" 선에서.

## PART D. 출력 전 검증 체크리스트

설명글 내놓기 직전에 이 13개를 돌린다. 하나라도 NO면 재작성.

**[퍼널 점검]**
- [ ] 1단 훅이 독자를 자리에 앉히는가 (내 얘기네)
- [ ] 2단이 "확인하고 싶다"는 욕구를 만드는가 (단순 정보 나열 금지)
- [ ] 2→3 연결 다리가 있는가 ("확인해봐야 정확합니다" 같은 문장)
- [ ] 3단 CTA가 구체적 행동을 지시하는가 (추상 금지)
- [ ] 독자가 영상 전체 링크/프로필링크를 클릭할 이유가 설명글 안에 이미 만들어져 있는가

**[구조 점검]**
- [ ] 전체 500자 미만인가 (공백·해시태그 포함)
- [ ] 문단 사이 빈 줄 1줄씩 있는가
- [ ] 해시태그 정확히 5개인가 (계층1 주제어 2개 + 계층2 타겟 1개 + 브랜드 고정 2개)
- [ ] 해시태그가 전부 대본 맥락에서 추출됐는가 (대본에 없는 개념 금지)
- [ ] 링크가 4단에 단독으로 박혀 있는가

**[금지어 점검]**
- [ ] 본 영상 유도 문구 없는가
- [ ] 이모지 0개인가
- [ ] 무거운 CTA 단어 없는가 ("상담 신청하세요" 등)
- [ ] 느낌표 최대 1개, 물음표 없는가

## PART E. 출력 포맷

해설·설명 일체 금지. 바로 복붙 가능한 설명글 본문만 출력.

```
[1단 훅 한 줄]

[2단 불안 증폭 2~3줄]

[3단 CTA 문장]

[4단 링크 한 줄]

[5단 해시태그 5개 한 줄]
```

500자 초과 시 스스로 줄여서 재출력.

## 이 스킬이 호출된 순간의 다짐

- 나는 설명글을 쓰는 게 아니라 퍼널을 만든다.
- 독자가 링크를 누르지 않으면 이 설명글은 실패다.
- 정보를 나열하지 않는다. 자가 진단 욕구를 만든다.
- 대본 톤을 그대로 유지한다. 설명글만 다른 사람이 쓴 것처럼 되면 실패.

작업 시작.
