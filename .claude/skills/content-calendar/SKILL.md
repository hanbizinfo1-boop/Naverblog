# 콘텐츠 캘린더 & 주제 배치 (content-calendar)

한 편씩 즉흥으로 쓰면 주제·구조가 자꾸 겹친다(자기복제).
이 스킬은 **여러 편을 한 번에 기획**하면서 골격·패턴·의도를 분산해
자기잠식을 근본부터 막는다.

## 입력
- 분야/키워드 풀 (예: 폐업지원금, 새출발기금, 매출없는사업자대출 ...)
- 기간 또는 편수 (예: 4주 / 12편)
- 발행 빈도 (예: 주 3회)
- (선택) 회원님 블로그 카테고리

## 처리 절차

### 1. 키워드 확장
주어진 키워드를 **메인 + 롱테일**로 확장한다.
- 메인: 폐업지원금
- 롱테일: 폐업지원금 신청조건 / 폐업 전 폐업지원금 / 폐업지원금 얼마 / 폐업지원금 새출발기금 차이
→ 롱테일이 경쟁 낮고 전환 높다. 초반은 롱테일 위주.

### 2. 검색 의도 분류 (글 방향)
각 키워드를 분류: 정보형 / 비교형 / 거래·신청형 / 후기·사례형.
→ 의도가 골격 선택에 영향.

### 3. 골격·패턴 분산 (★ 핵심)
`posts/_variation-log.md`를 읽고, 캘린더 안에서 **연속된 글이 같은 조합을 안 쓰게** 배치한다.
- 본문 골격 S1~S3을 번갈아 (연속 같은 번호 금지)
- 제목 패턴 T1~T6을 번갈아 (연속 같은 번호 금지)
- 도입 훅 유형(결과선공개/오해반박/질문/숫자)도 번갈아

### 4. 발행일 매핑
빈도에 맞춰 날짜를 붙인다. 타겟 검색 시간대 고려(직장인 출퇴근·점심).

## 산출물 형식

```
■ 콘텐츠 캘린더 (N편 / 기간)

| 발행일 | 메인키워드 | 롱테일 | 의도 | 골격 | 제목패턴 | 도입훅 | 비유 |
|--------|-----------|--------|------|------|---------|--------|------|
| 6/12   | 폐업지원금 | 신청조건 | 정보 | S1 | T2 | 숫자 | 없음 |
| 6/14   | 새출발기금 | 80%탕감 | 정보 | S2 | T4 | 결과선공개 | 조건부 |
| 6/16   | 매출없는사업자대출 | 신규 | 비교 | S3 | T3 | 오해반박 | 없음 |
...

■ 분산 점검: 골격 연속중복 0 / 제목패턴 연속중복 0 / 의도 편중 여부
■ 다음 액션: "6/12 글부터 쓸까요?" → naver-seo-geo-blog로 연결
```

## 변주 로그 연동
- 캘린더를 확정하면 각 행을 `posts/_variation-log.md`에 **예약 기록**해도 된다(발행 시 확정).
- 글을 실제 발행할 때마다 로그를 최신화해 다음 기획 때 중복을 피한다.

## 도구 참고
실제 검색량/경쟁도는 외부 도구(네이버 키워드도구, 블랙키위)로 보완하라고 안내한다.
이 스킬은 **기획·분산·일정**을 책임지고, 정량 데이터는 외부에서 가져온다.
