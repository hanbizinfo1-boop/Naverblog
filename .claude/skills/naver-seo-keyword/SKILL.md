# 네이버 SEO 키워드 설계 (Naver SEO Keyword)

네이버 검색 상위노출의 출발점인 **키워드와 검색 의도**를 설계하는 스킬이다.
좋은 글도 키워드가 어긋나면 노출되지 않는다.

## 핵심 개념

- **C-Rank**: 블로그(출처)의 신뢰도·전문성 점수. 한 주제를 꾸준히 쓰는 블로그가 유리.
- **D.I.A.+ (Deep Intent Analysis)**: 문서 단위로 "검색 의도에 얼마나 잘 답했나"를 본다. 키워드 반복이 아니라 **의도 충족**이 핵심.
- 따라서 키워드 전략 = "검색량 있는 키워드" × "내가 신뢰도 있게 답할 수 있는 주제" × "경쟁 강도".

## 키워드 3단 구조

1. **메인 키워드** (1개): 글 전체 주제. 검색량 크지만 경쟁도 큼. (예: `강남 맛집`)
2. **세부/롱테일 키워드** (2~4개): 메인+수식어. 경쟁 낮고 전환 높음. **초보 블로그는 여기서 승부.** (예: `강남역 혼밥 맛집`, `강남 데이트 코스 맛집`)
3. **연관 키워드** (3~5개): 본문·태그에 자연스럽게 녹일 보조어. (예: `주차`, `웨이팅`, `가격`)

## 검색 의도 분류 (글 방향 결정)

키워드를 잡으면 의도부터 분류한다.

| 의도 유형 | 예시 키워드 | 글이 줘야 할 것 |
|----------|-----------|---------------|
| 정보형 | "OO 증상", "OO 방법" | 정확한 정보·단계 설명 |
| 비교형 | "A vs B", "OO 추천" | 비교표·장단점 |
| 거래/방문형 | "OO 맛집", "OO 가격" | 위치·가격·예약·실사진 |
| 후기형 | "OO 후기", "OO 사용기" | 직접 경험·솔직한 평가 |

→ 분류 결과를 `naver-blog-writer`에 전달해 구조를 맞춘다.

## 키워드 배치 가이드 (감점 안 나게)

- **제목**: 메인 키워드 1회 자연스럽게. 키워드 반복·나열 금지.
- **첫 문단**: 메인 키워드 1회.
- **본문**: 메인+세부 키워드를 전체 글에서 자연스럽게 분산. **키워드 밀도 강박 금지** — 억지로 넣으면 D.I.A.+ 감점.
- **소제목**: 세부/연관 키워드 활용.
- **태그**: 메인+세부+연관 5~10개.

## 제목 후보 작성 규칙

> ⚠️ **제목 길이·패턴의 주인은 이 파일이 아니다.**
> `naver-seo-geo-blog` 의 [제목 설계 룰]을 따른다 — **30~38자, 25자 이하 금지, T1~T6 패턴 로테이션.**
> 아래는 그 규칙 안에서 후보를 뽑는 보조 지침이다. 길이 규칙은 여기서 정하지 않는다.

- [메인키워드] + [구체 수식어 / 숫자 / 후킹] 형태.
  - 예) `강남역 혼밥 맛집 BEST3, 웨이팅 없이 다녀온 곳`
- 낚시성 과장("충격", "실화") 지양 — 체류시간 떨어지면 역효과.

## 도구 참고

- 실제 검색량/경쟁도 데이터가 필요하면 사용자에게 **네이버 키워드도구, 블랙키위(BlackKiwi), 키워드마스터** 활용을 안내한다. (이 스킬은 전략·구조를 잡고, 정량 데이터는 외부 도구로 보완)
