# 네이버 블로그 발행 점검 (Naver Blog Publish)

작성된 글을 **발행 직전에 점검**해 저품질·정책 위반을 거르고 노출 확률을 높이는 스킬이다.

## 발행 전 최종 체크리스트

작성된 글을 받아 아래를 하나씩 점검하고, 통과/수정필요로 표시해 보고한다.

### 1. 콘텐츠 품질
- [ ] 분량 1,500~2,000자 내외인가
- [ ] 도입 3줄에서 핵심을 던지는가(역피라미드)
- [ ] 검색 의도에 직답하는가 (키워드 나열 글 아님)
- [ ] 구체적 경험·수치·정보가 있는가(신뢰성)
- [ ] 소제목으로 구획돼 모바일에서 스캔 가능한가

### 2. 키워드/제목
- [ ] 제목에 메인 키워드 1회, 25자 내외인가
- [ ] 키워드 억지 반복(밀도 강박) 없는가
- [ ] 낚시성 과장 제목 아닌가

### 3. 멀티미디어
- [ ] 이미지 10장 이상 배치 위치 표시됐는가
- [ ] 직접 촬영 이미지 위주인가 (무료 스톡 도배 = 감점)
- [ ] 동영상(15초+) 1개 위치 있는가(가산점)
- [ ] 첫 이미지(대표)가 매력적인가

### 4. 정책/저품질 리스크
- [ ] 협찬·체험단이면 **대가성 문구 명시**했는가 (정책+공정위)
- [ ] 의료/건강 과장, "최고/100%/완치" 등 단정 표현 없는가
- [ ] 상업적 외부 링크 도배 없는가
- [ ] 타사 비방·허위·복붙(중복문서) 없는가

## 해시태그 정리

- 개수: **5~10개** (과도하면 스팸 신호).
- 구성: 메인 키워드 + 세부 키워드 + 연관 키워드 조합.
- 형식: `#키워드` 공백 없이.
- 예: `#강남맛집 #강남역혼밥 #강남데이트코스 #강남역점심 #웨이팅맛집`

## 발행 타이밍 가이드

- **타겟 독자가 검색하는 시간대**에 발행 (점심 맛집 → 오전 11시~12시, 직장인 정보 → 출퇴근/저녁).
- 일반적으로 평일 오전·저녁, 주말 오전 노출이 유리.
- 발행 직후 1시간은 초기 반응(체류·댓글)이 노출에 영향 → 이웃에게 알림 등 초기 유입 도움.

## 발행 후 관리 팁

- 발행 후 **본문 잦은 수정 자제**(특히 발행 직후 대규모 수정은 재평가 유발).
- 오탈자·이미지 누락은 발행 전에 잡는다.
- 댓글에 성실히 답 → 체류·신뢰도에 긍정적.
