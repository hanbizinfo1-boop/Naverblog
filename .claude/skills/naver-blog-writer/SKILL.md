# 네이버 블로그 글쓰기 (Naver Blog Writer)

> ⚠️ **이 스킬은 정책자금이 아닌 범용 주제 전용이다.**
> 박관장 정책자금 글은 `naver-seo-geo-blog` 가 쓴다. 두 스킬을 섞지 않는다.
> 제목 길이·화자·문체는 이 파일이 주인이 아니다 — `naver-seo-geo-blog` 를 따른다.
> 시각 서식(줄길이·문단·강조·이미지 배치)은 `templates/템플릿-0N-*.md` 가 주인이다.
> 전체 작업 순서는 `길라잡이.md` 작업 C 참고.

네이버 검색 상위노출에 최적화된 블로그 포스팅을 작성하는 스킬이다.
단순히 글을 길게 쓰는 게 아니라 **네이버 검색 알고리즘이 좋아하는 구조**로 쓴다.

## 작성 전 반드시 확인할 4가지

글을 쓰기 전에 아래가 정해지지 않았으면 사용자에게 한 번에 물어본다.
(이미 대화에 있으면 다시 묻지 않는다.)

1. **주제/소재** — 무엇에 대한 글인가 (예: OO카페 방문 후기)
2. **타겟 키워드** — 검색 노출을 노리는 핵심 키워드 (없으면 `naver-seo-keyword` 스킬로 먼저 잡는다)
3. **글 성격** — 정보성 / 후기·리뷰 / 협찬·체험단 / 일상
4. **협찬 여부** — 대가성 글이면 **본문에 '협찬/체험단' 문구 명시 필수** (네이버 정책 + 공정위 표시)

## 네이버 상위노출 핵심 원칙 (이 글에 반드시 반영)

- **검색 의도 > 키워드 반복**: 키워드를 많이 박는 글은 오히려 감점(D.I.A.+ = Deep Intent Analysis). 검색한 사람이 진짜 궁금해할 답을 정확히 준다.
- **적합성 · 신뢰성 · 최신성** 3축으로 평가된다. 직접 경험·구체적 정보·최신 정보를 넣는다.
- **분량**: 정보성 기준 **1,500~2,000자** 내외(공백 제외 기준 아님, 전체 글자 수). 너무 짧으면 정보 부족, 너무 길면 이탈률↑.
- **이미지**: 컷 수와 배치는 그 글의 `templates/템플릿-0N-*.md` 가 정한다. 무료 스톡 다수 사용은 **감점 요인**이라 직접 촬영본을 우선한다. 본문에는 `(사진1)` `(사진2)` 형태로 자리를 표시하고, 파일은 `사진1.jpg` 로 1:1 대응시킨다 (`templates/작성-운영규칙.md` 2항).
- **동영상**: 15초 이상 영상 1개 포함 시 가산점 → 가능하면 영상 삽입 위치도 표시.
- **체류시간**: 첫 3줄에서 이탈 안 되게 핵심을 먼저 던진다(역피라미드).

## 글 구조 — 역피라미드 템플릿 (기본형)

```
[제목]  ← 타겟 키워드 자연스럽게 포함, 30~38자 (naver-seo-geo-blog 제목 설계 룰), 클릭 유도

1. 도입 (3줄 요약 / 후킹)
   - 결론·핵심을 먼저. "오늘은 ~를 정리해봤어요" 식의 늘어지는 도입 금지.
   (사진1)  ← 대표 사진

2. 핵심 답변 (독자가 검색한 이유에 대한 직답)
   - 가장 궁금해할 정보를 바로 제공 (위치/가격/결론/추천 여부 등)
   (사진N)

3. 상세 설명 (소제목으로 구획)
   - 소제목 2~4개로 나눠 스캔 가능하게.
   - 구체적 수치·경험·비교를 넣어 신뢰성 확보.
   (사진2) (사진3)  ← 섹션마다 배치, 번호는 이어서
   [동영상: 가능하면 1개]

4. 개인 소감 / 마무리 + CTA
   - 솔직한 장단점, 추천 대상.
   - 댓글·이웃추가 유도 1줄.

5. 태그 (#키워드 5~10개) ← naver-blog-publish 스킬에서 정리
```

## 톤앤매너 규칙

- **기본 톤**: 친근한 존댓말("~했어요", "~더라고요"). 사용자가 별도 톤을 지정하면 그걸 우선.
- **문단**: 모바일 가독성 위해 2~3문장마다 줄바꿈. 한 문단이 길지 않게.
- **이모지**: 과하지 않게 섹션당 0~2개.
- **AI 티 제거**: "결론적으로", "종합해보면", "~라고 할 수 있습니다" 같은 기계적 표현 지양. 실제 경험담처럼.

## 금지·주의 표현 (네이버 저품질/광고 규제 회피)

- **의료·건강 과장**: "치료", "완치", "효능 보장" 등 단정 표현 금지(특히 건강기능식품·병원 글).
- **최상급 단정**: "최고", "100%", "무조건" 남발 금지 → 저품질 신호.
- **외부 링크 도배**: 본문에 상업적 외부 링크 다수 삽입 금지.
- **타사명 비방·허위**: 금지.
- **협찬 미표기**: 대가 받은 글에 표기 누락 = 정책 위반. 반드시 명시.
- 추가 금지어가 있으면 `assets/forbidden-words.txt`(있을 경우)를 읽어 함께 필터링한다.

## 작성 워크플로우

1. 위 4가지 확인 → 키워드 미정이면 `naver-seo-keyword` 호출 제안.
2. 역피라미드 템플릿으로 초안 작성 (이미지/동영상 위치 표시 포함).
3. 분량(1,500~2,000자)·금지표현·협찬표기 자가 점검.
4. 사용자에게 초안 제시 → 수정 반영.
5. 발행 직전 `naver-blog-publish` 스킬로 제목·태그·최종 체크리스트 정리.

## 산출물 형식

- 기본은 채팅에 마크다운으로 보여준다.
- 사용자가 "파일로", "저장해줘" 하면 `posts/YYYY-MM-DD-주제.md`로 저장한다.
- 사용자가 워드/PDF로 달라고 하면 docx/pdf 스킬과 연계한다.
