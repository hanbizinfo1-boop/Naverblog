# 뼈대 5종 — 글의 순서

> 같은 틀로 찍어 내면 네이버가 «양산형»으로 본다. **뼈대를 돌려 쓰고, 같은 뼈대를 연속 2번 쓰지 않는다.**
> 같은 뼈대여도 도입 방식·분량·사진 수·맺음말을 글마다 바꾼다(아래 «변주»).
> 원고 머리 `종류:`(설명·이야기·사례·소식) 와 `뼈대:`(A~E)를 적는다 — 기록이 남아야 다음 글이 다른 뼈대를 고른다.

## 고르는 법
| 오늘 재료 | 뼈대 |
|---|---|
| 제품·서비스·시술 하나를 실물 사진으로 | A 설명 |
| 브랜드·지역·가게·기술의 역사 | B 연대기 |
| «왜 그런가», 고르는 법, 관리법 | C 원리 |
| 손님이 겪은 문제를 가게가 해결한 과정 | D 사례 (★ 의료·법률·금융은 업종 금지선 먼저 — 치료 경험담·전후 비교가 금지인 업종이 있다) |
| 휴무·행사·시즌 안내 | E 소식(짧게, 일정 칸) |

## A. 설명형 — «전문가가 하나를 풀어 준다» (실사진 + 빨간 표시)
| 막 | 하는 일 |
|---|---|
| 도입 | 인사(색) → 오늘 볼 것 1~2문단 → 손님이 자주 묻는 질문 한 줄(형광) |
| 전체 사진 | 주인공 정면(가운데 맞춤) |
| 부분 절 3~5개 | 소제목(질문형 또는 «~입니다») → **표시 넣은 실사진** → 설명 1~3문단 |
| 전문가가 보는 것 | 맞춤·확인 과정(그 업종 자격 범위 안에서, 효과 단정 ✗) |
| 정리 | 다른 색·비교 → 한눈에 정리(번호 목록) → 자주 묻는 질문 2~3개 |
| 맺음 | 혜택(있으면) → 찾아오시는 길 |
- 끝맺음 «~요»·«~습니다»를 섞는다. 사진 1장 아래 설명은 1~3문단.

## B. 연대기형 — 다큐 해설 (브랜드·지역·역사)
| 막 | 하는 일 |
|---|---|
| 도입 | 인사 1줄 → 대상 한 줄 정의 → «A 대신 B» 철학 1문단 → 사진 |
| 기원 | 언제·누가·어디서 + 당시 배경 |
| 위기·결단 | «그러나 ~» → «이때 결단을 내립니다» → 결단 한 문장 **굵게** |
| 사람·기술 | 같은 틀 2~4번 반복: 소제목(이름) → 사진 → 이력(연도) → 기술 → 여운 한 줄 |
| 소재·방식 | 대비 하나로 «어려운데 왜 고집하나» |
| 확장 | 연도순 사건·시설 + 장소 사진 |
| 정리 표 | 2열 표(종류 | 특징) |
| 오늘의 의미 | 큰 인용 1개(공식 문장, 출처) → 철학 1문단 |
| 맺음 | 손님이 쓸 때 느끼는 것(사실만) → 처음과 잇는 한 문장 → 가게 사진 + 가게에서 볼 수 있는 것 → 찾아오시는 길 → 참고 |
- 가게 이야기는 **맺음에서만**. 본문 중간에 «저희 매장에서» 끼우지 않는다.

## C. 원리형 — «왜 그런가» (선택법·관리법·개념)
| 막 | 하는 일 |
|---|---|
| 도입 | 손님이 실제로 묻는 질문 한 줄 → 오늘 풀 것 → **첫 문단에 답 2~3문장**(AI 답변·검색 요약에 그대로 인용되게) |
| 짧은 역사 | 이 개념·도구가 언제 생겼나(연도 1~2개) |
| 원리 | 무엇이 어떻게 다른가 — 대비 하나 + 사진 |
| 구분 | 종류별 소제목 2~4개(같은 틀 반복) |
| 비교 표 | 2열 표 |
| 가게에서 | 전문가가 하는 일(자격 범위 안) |
| 맺음 | 정리 1문단 → (건강·법률·돈 관련이면) «정확한 판단은 ○○ 전문가와 상담» → 찾아오시는 길 → 참고 |

## D. 사례형 — 문제 → 원인 → 해결
| 막 | 하는 일 |
|---|---|
| 문제 | 손님이 겪던 불편(개인 특정 정보 ✗, 동의 없는 얼굴 ✗) |
| 원인 | 왜 그랬나 — 사진에 빨간 상자·화살표로 짚기 |
| 해결 | 가게가 한 일(과정 사진) |
| 결과 | 달라진 점은 **관찰 가능한 사실만**(«흘러내리지 않게 조였습니다» ✓ / «완벽해졌습니다» ✗) |
| 맺음 | 비슷한 불편이 있으면 → 찾아오시는 길 |

## E. 소식형 — 짧게
인사 → 무엇이 언제 바뀌나(날짜·시간 표 또는 목록) → 이유 한 줄 → 대안(예약·문의) → 찾아오시는 길. 600~1,000자.

## 변주 — 같은 뼈대도 매번 다르게
- 도입(택1): 손님 질문 / 상황 공감 / 계절 / 대상 한 줄 정의 / 숫자 하나
- 분량: 1,500~3,000자 안에서 글마다 다르게(전부 2,000자 고정 ✗)
- 사진 수: 4~10장, 캡션도 매번 다른 문장
- 맺음: 방문 / 예약 / 상담 권유를 돌려 쓴다
- **하지 않는 구성**: «아침엔 ~ 점심엔 ~ 저녁엔 ~» 하루 따라가기 서사 · 은유·비유(«선이 사라진다» → «테가 얇아 얼굴을 덮는 면적이 작습니다»)

## 로테이션 기록 (업체설정 7번 «발행 기록»)
| 날짜 | 종류 | 뼈대 | 주인공(제품·주제·모델) |
- 쓰기 전에 마지막 3편을 본다: 같은 뼈대 연속 ✗ · 같은 주인공 3회 연속 ✗(그러면 쓰지 말고 운영자에게 알린다)
- 같은 주제를 다시 쓸 때는 각도를 바꾼다(가격대·관리법·비교·사례). 지난 글 문장을 옮기지 않는다
