# 말투와 문장

## 1. 두 가지 목소리 — 글 종류로 고른다
| | 설명형·사례형·소식형 | 이야기형(연대기·원리) |
|---|---|---|
| 화자 | 그 업종 전문가가 손님 앞에서 설명 | 다큐멘터리 해설자 |
| 끝맺음 | «~요»와 «~습니다»를 번갈아(같은 끝 3문단 연속 ✗) | **합쇼체**(~습니다·~입니다) 끝까지. «~요»는 첫·끝 인사만 |
| 독자 부르기 | 가끔(«~하신 적 있으시죠») | ✗ — 차분한 3인칭. 감탄·느낌표 ✗ |
| 시제 | 현재 | 과거형 + 전환점만 역사적 현재(«결단을 내립니다») |
| 잇는 말 | 그래서 · 그런데 · 예를 들어 | 당시 · 그러나 세월이 흐르며 · 이때 · 이에 따라 · 이를 바탕으로 |

## 2. 사람이 쓴 글처럼 (AI티 빼기)
| 쓰지 않는다 | 대신 |
|---|---|
| «~를 통해» «~에 있어» «~에 의해» «가지고 있다» | «~로» «~에서» «~가» «있다» |
| «결론적으로» «또한» «즉» «시사하는 바» | 그냥 다음 문장 |
| 혁신적·압도적·최고의·완벽한·유일한·폭발적 | 연도·횟수·방법·소재 같은 사실 |
| 트렌디·핫한 | 무엇이 어떻게 다른지 |
| 심플한·깔끔한·예쁜·좋은(빈약 묘사) | «테 두께 2mm», «손잡이 모서리를 둥글게 갈아» |
| 은유·비유(«선이 사라진다», «세월의 멋») | 관찰 가능한 사실(«테가 얇아 얼굴을 덮는 면적이 작습니다») |
| 한 문단에 «~할 수 있습니다» 3번 | 단정할 수 있는 건 단정, 아니면 뺀다 |
| 불릿 나열로 본문 채우기 | 문단(목록은 «한눈에 정리»에서만) |
- 짧은 문장과 긴 문장을 섞는다. 같은 문형 연속 ✗.
- 대비로 설명하면 잘 읽힌다: «A 대신 B» · «A가 ~하는 반면 B는 ~».
- 고유명사 첫 등장엔 원어 병기: 셀룰로이드(Celluloid).

## 3. 사실 — 추측이 섞이면 그대로 발행된다
- **쓰기 전에 사실 메모부터**: 연도·인물·지명·숫자·인용마다 출처 URL. 메모에 없는 사실은 글에 넣지 않는다.
- 쓸 수 있는 출처: 공식 사이트 · 정식 유통사 · 학회·정부·공공기관 · 구매 인증이 있는 실구매 후기(요지만, «후기에서 ~라는 말이 많다»).
- 쓸 수 없는 출처: 개인 블로그 · 인플루언서 글 · 출처 없는 요약 — **잘 쓴 레퍼런스 블로그도 사실의 출처가 아니다**(실제로 창업자 이름·연도 순서가 틀린 인기 글이 있었다).
- 숫자는 «공식 출처에 적힌 값 + 출처 URL» 이면 쓴다(무게·치수처럼 검색이 잘 되는 숫자). 출처 없는 숫자는 빼고, 가격은 바뀌므로 쓰지 않는다.
- **사진에 없는 것을 쓰지 않는다** — 쓰기 전에 사진 파일을 직접 연다. 계절·시간·날씨·옷차림은 보이는 대로만(실제 사고: 한여름 낮 반팔 사진을 «저녁 산책»으로 씀).
- 손님 통계(«많이 찾습니다», «인기») ✗ — 확인할 수 없다. «~께 맞습니다» 추천으로.
- 건강·효능·법률·돈 이야기는 «~를 권합니다(출처)» 꼴로만 옮기고, 맺음은 «정확한 판단은 전문가 상담».

## 4. 검색·AI 답변에 인용되게 (AEO)
- 첫 문단 2~3문장에 **질문의 답**을 먼저. 업체 정의 문장 한 번(«○○는 △△동에 있는 □□입니다»).
- 소제목은 손님이 검색창에 치는 질문 그대로, 각 절 첫 1~2문장은 혼자 떼어 읽어도 답이 되게.
- 자주 묻는 질문 2~5개(`Q.`) — 답은 2~3문장, 첫 문장에 답이 다 들어가게. 지역명 한 번.
- 작성자 전문성(경력 연수·자격)을 사실로 한 번.

## 5. 키워드 — 문장 속에 자연스럽게
- 상호 정식 이름은 첫 등장 1번, 다음부터 «저희»·짧은 이름.
- 지역+업종 키워드 글 전체 3~5회, 형태를 바꿔(«세종 ○○» / «보람동 ○○» / «시청 앞 ○○»), 한 문단에 같은 키워드 2번 ✗.
- ✗ 나쁜 예: «세종의 ○○인 세종 ○○ 세종시청점에서 세종 ○○을…» — 떡칠은 저품질 신호.
- 주제와 무관한 트래픽 키워드(인사말 모음 등) 글 ✗ — 블로그 주제 집중도(C-Rank)가 흐려지고 체류시간이 깎인다. 계절 키워드는 업종 주제 안에서(«장마철 ○○ 관리»).

## 6. 레퍼런스(잘 쓴 남의 글)를 받으면
- 먼저 운영자 의도를 확인: «이렇게 써 줘(학습)»인가 «이 틀에서 벗어나고 싶어(탈피)»인가 — 반대로 해서 다시 쓴 적이 있다.
- 배우는 것: 순서·장치·말투·서식(분해해서 표로). 가져오지 않는 것: 문장·소제목·사실·사진(저작권·유사문서).
