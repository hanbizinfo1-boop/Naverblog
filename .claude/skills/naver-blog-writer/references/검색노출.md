# 검색 노출 — 네이버 블로그가 «잘 걸리게»

> 네이버 검색 내부 기준(C-Rank·D.I.A.)은 공개되지 않는다. 아래는 공식 발표·실무에서 반복 확인된 것 + 운영하며 겪은 것이다. 확정 수치처럼 말하지 않는다.

## 1. 제목
- 15~40자(도구 ⚠). **지역 + 업종(또는 대상) + 오늘의 핵심** 한 번씩: «세종 보람동 ○○, △△ 고를 때 보는 세 가지»
- 키워드는 메인 1 + 보조 1까지. 떡칠 ✗. 낚시성 물음표·과장 ✗
- 공식 출처가 있는 구체 숫자는 제목에서 힘이 세다(실제: 무게 숫자를 제목에 넣은 글이 조회 422회)

## 2. 태그
5~10개. 지역+업종 조합 2~3 · 오늘 주제 2~3 · 브랜드·제품 1~2. 본문과 무관한 인기 태그 ✗.

## 3. 본문
- 첫 문단에 메인 키워드 1번 + 질문의 답(AEO — references/말투_문장.md 4번)
- 소제목에 보조 키워드·롱테일(손님이 치는 질문 그대로)
- 실사진(원본성) · 매번 다른 사진 설명
- 글 끝 «찾아오시는 길» — 상호·주소·전화 **늘 같은 표기**(지도·플레이스와 같은 업체로 읽히게) + 예약·지도 링크
- 홈페이지가 있으면 주소 한 줄(블로그 → 홈페이지 연결). 블로그 프로필에도

## 4. 유사문서·양산형 피하기 (가장 많이 잃는 곳)
- **같은 글을 두 곳에 올리지 않는다** — 네이버는 문장 단위로 비교해 먼저 색인된 쪽을 원본으로 본다(«프로젝트 BiO»). 홈페이지·인스타·플레이스와 문장 복붙 ✗, 채널마다 새로 쓴다
- 뼈대 로테이션(references/뼈대.md) · 같은 주인공 3회 연속 ✗ · 대표 사진 재사용 ✗
- 고정 문구(인사·맺음) 반복 ✗ — 풀에서 바꿔 쓴다
- 지난 글 문장 재사용 ✗ — 같은 주제는 각도를 바꿔
- 레퍼런스 글 문장 옮기기 ✗

## 5. 주제 집중
- 블로그 하나 = 업종 주제 하나. 트래픽용 무관 글(인사말·연예 등) ✗
- 시즌 키워드는 업종 안에서: «장마철 ○○ 관리», «개학 전 ○○»
- 같은 주제를 의도별로 나눠 여러 글로(가격대 · 고르는 법 · 관리법 · 비교 · 사례) — 한 키워드 1등 다툼보다 롱테일 여러 개

## 6. 발행
- 자동 발행 프로그램·매크로 ✗ — 네이버 약관이 자동화 수단 게재를 막는다(사람이 복사·붙여넣기·발행 버튼을 누르는 건 해당 없음). 글쓰기 API 는 2020년 종료
- 네이버 «예약 발행»은 공식 기능 — 몇 편 미리 써 두고 요일에 맞춰 건다
- 일정한 주기(주 3편 등)가 들쭉날쭉보다 낫다(실무 경험칙, 공식 수치 아님)
- 발행 뒤 성과(조회·공감·댓글)를 업체설정 «발행 기록»에 적는다 — 무엇이 잘 됐는지는 숫자로만 판단한다
