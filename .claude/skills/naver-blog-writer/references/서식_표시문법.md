# 서식 — 원고 문법과 모바일 가독성

> 네이버 블로그는 **휴대폰으로 읽힌다.** 서식 규칙은 전부 «휴대폰 한 화면에서 숨 막히지 않게»가 목적이다.
> 원고(글.md)를 이 문법으로 쓰면 `scripts/blogkit.py` 가 검사하고 «복사용 페이지»를 만든다 → 운영자는 «본문 전체 복사 → 붙여넣기»만 한다.
> (서식 꾸미기를 손으로 하면 한 편에 30~40분 — 이 시간을 없애는 게 목적이었다.)

## 2. 표시 문법
| 쓰기 | 결과(네이버에 붙이면) | 쓰는 자리 |
|---|---|---|
| `## 소제목` | 인용구 상자 → 붙인 뒤 인용구 모양을 고른다(포스트잇·말풍선 등) | 절 제목 3~7개 |
| `[사진 N]` | 파란 «사진 자리» 줄 — 붙인 뒤 그 자리에 사진 버튼으로 N번 사진 | 사진마다 |
| `**굵게**` | 굵게 | 핵심 낱말·짧은 구(8자 안), 한 문단 한 곳 |
| `{자}…{/}` | 자주 굵게 | 첫 인사, 용어 풀이 첫 줄 |
| `{형}…{/}` | 주황 형광 굵게 | 그 절에서 **가장 중요한 문장 하나** |
| `{노}…{/}` | 노랑 형광 굵게 | 보조 강조 |
| `{빨}…{/}` | 빨강 굵게 | 결론·권유·주의 한 줄 |
| `{초}…{/}` `{분}…{/}` | 초록·분홍 굵게 | 혜택·할인 칸에서만 |
| `{파}…{/}` | 파랑 굵게 | 다시 나온 고유명사·용어 |
| `{큰}…{/}` | 20px 굵게 | 절마다 한 번 정도 — 수치·핵심 한 줄 |
| `{이}…{/}` | 살구 바탕·테두리 | 사람 이름 **처음 나올 때** |
| `{고}…{/}` | 하늘 바탕·파랑 테두리 | 기관·제도·용어·작품 이름 **처음 나올 때** |
| `{연}…{/}` | 주황 글자 | 연도·숫자·단위 |
| `{지}…{/}` | 청록 글자 | 지명 |
| `> 문장` | 테두리 상자(인용구) | 도입 질문·용어 풀이·혜택·법 인용 |
| `>> 문장` | 큰 인용(가운데·기울임·따옴표 자동) | 글 전체 1개, 출처 있는 문장만 |
| `Q. 질문` (다음 줄부터 답) | 굵은 질문 줄 + 답 문단 | 자주 묻는 질문 2~5개 |
| `\| 머리 \| 머리 \|` 줄 이어 쓰기 | 표(첫 줄이 머리) | 비교·정리 1개 |
| `[구분선]` | 가는 가로줄 | 큰 막이 바뀔 때 1~2번 |
- **색을 넣는 곳은 전부 굵게**(도구가 자동). 색만 있고 가늘면 휴대폰에서 안 보인다.
- 테두리(`{이}`·`{고}`)는 «처음 한 번», 그다음은 글자색(`{파}`) — 그래야 테두리와 글자색이 섞여 리듬이 생긴다.

## 3. 줄과 문단 (도구가 ⚠ 로 잡는다)
| | 설명·사례·소식 | 이야기 |
|---|---|---|
| 한 줄 | **18~20자**(공백 포함) — 넘으면 기기가 멋대로 꺾는다 | **24자 안**(괄호 속 원어·숫자 단위는 안 셈) |
| 끊는 자리 | 조사·쉼표·«~고/~서/~면» 뒤 | 쉼표·«~는/~고/~며» 뒤, **나열 앞**(«증상은 / 피로, 두통, …») |
| 끊지 않는 자리 | 낱말·숫자·모델명 가운데(`KC-60N`·`1.9g` 은 한 줄에) | «것·수·때·데» 앞 |
| 한 문단 | 2~4줄(1줄 문단은 글 전체 3개까지) | 2~7줄 |
| 정렬 | 가운데 | 가운데 |
- 문단 사이 빈 줄 1개, **사진·소제목 앞뒤도 1개** — 도구가 «빈 문단»으로 넣는다(네이버는 여백을 버리고 빈 문단만 남긴다). (운영자 교정 2026-10-06: 2개 → 1개)
- «찾아오시는 길»·«참고·출처» 절은 **왼쪽 정렬**(주소·링크는 가운데면 읽기 어렵다) — 도구가 소제목 이름을 보고 자동.
- 사진 1장 뒤 글 1~3문단 → 다음 사진. 사진-글-사진 리듬이 끊기지 않게.

## 4. 강조의 양 — «적으면 밋밋, 많으면 시끄럽다»
- 설명형: **강조 없는 문단 0개**가 목표(색·굵게·상자 중 하나). 절마다 상자(`> `)나 `{큰}` 하나. 형광 문단은 절마다 2개까지
- 이야기형: `**굵게**` 글 전체 2~5곳(결단·핵심), 색 표시 3곳 + 이름·연도·지명·고유명사 표시. 차분하게
- 브랜드·제품 이름 자체는 굵게 하지 않는다(검색에 도움 없음, 지저분)
- 성과 근거: 이 규칙을 만든 안경원 블로그에서 조회 422회로 가장 잘 된 글이 «가운데 정렬 + 자주 인사 + 절마다 형광 한 문장 + 빨강 결론» 이었다 — 이 체계가 출발점

## 5. 네이버 편집기에 붙여 넣으면 (2026-09 실측)
| 살아남음 | 미확인 | 안 됨 |
|---|---|---|
| 글자색 · 굵게 · 형광(바탕색) · 글자 크기 · 가운데 정렬 · 인용구(`blockquote`) · 구분선 · 나눔고딕 16 | 표 · 테두리(`{이}`·`{고}` 의 외곽선) · 인용구 모양 미리 정하기 | **사진** — 붙여도 네이버에 올라가지 않고 링크로만 남는다(라이브러리에 안 잡힘) → 반드시 사진 버튼으로 올린다 |
- «미확인»은 첫 글을 붙인 뒤 운영자 화면 캡처로 확인하고 업체설정에 적는다. 깨지면 그 표시를 쓰지 않는다.
- 붙인 뒤 글씨체가 나눔고딕이 아니면: 본문 클릭 → Ctrl+A → 나눔고딕.
- 홈페이지에 같은 글을 먼저 올려 두고 블로그에 붙이면 **유사문서**로 밀릴 수 있다 — 복사용 페이지는 검색 제외(noindex)·로컬 파일로만 쓴다.
