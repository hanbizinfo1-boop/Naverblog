## 2. 발행 순서 (편마다)

1. `복사용.html` 열기 → **제목 복사** → 네이버 제목 칸
2. **본문 전체 복사** → 본문에 붙이기
3. 파란 «사진 N 자리»마다 사진 버튼으로 `올릴사진/` N번 파일 (붙여넣기로는 안 올라간다)
4. 소제목은 인용구로 붙는다 → 인용구 모양 고르기
5. 글씨체가 나눔고딕이 아니면 본문 클릭 → Ctrl+A → 나눔고딕
6. 태그 복사 → 태그 칸
7. 맨 아래 네이버폼 주소가 링크 카드가 안 되면 링크 카드로 다시 넣기
