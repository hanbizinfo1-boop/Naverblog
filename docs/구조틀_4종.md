# 구조틀 4종 — 같은 품질, 다른 뼈대

> 왜 만들었나 (2026-10-06): 1006 7편은 내용과 품질은 괜찮았다. 문제는 7편의 틀이 같다는 것이다.
> 문단 순서, 첫 문장, 전환 문장까지 같아서 **저품질(양산형) 판정**이 걱정됐다.
> 실측 결과 7편 서로 간 **구조 유사도 0.71~0.91**, **같은 문장 4~8개**였다 (`scripts/유사도검사.py`).
> 이 문서는 품질 기준(v7·대표님 결정)은 그대로 두고 **뼈대만 4가지로 나눈다.**

길라잡이 2-2 판정표의 값(호칭·분량·정렬·글자색·고정 마무리·정합성 등)은 네 틀 모두 그대로 지킨다.
이 문서가 정하는 것은 **순서·리듬·전환 문장**이다.

| | 틀 1 «뒤집기» | 틀 2 «체크리스트» | 틀 3 «결과부터» | 틀 4 «갈림길» |
|---|---|---|---|---|
| 한 줄 | 오해를 깨고 사례로 증명 | 답부터 주고 항목별로 짚기 | 승인 장면에서 시작해 되감기 | 둘 중 뭘 고를지 나란히 비교 |
| 유형 · 원고 머리 | 사례 · `뼈대: D` | 정보 · `뼈대: A` | 사례 · `뼈대: D` | 정보 · `뼈대: A` |
| 이런 주제에 | «~면 안 된다»는 오해가 있는 자금 (매출 감소·업력·신용) | 금리표·요건·서류·사용처처럼 **목록**이 본론인 것 | 사례 한 건이 곧 설명인 것 (긴급·대환·상환연장) | 비슷한 두 제도·두 방식 (직접/대리, 일반/혁신, 연장/대환) |
| 이미지 느낌 (8번) | **대비** — 가로 장면 + 빨간 테두리 | **자료집** — 세로 확대 크롭 + 번호 | **다큐** — 세로 현장 사진, 따뜻한 톤 | **대칭** — 짝으로 붙는 가로 사진 |
| 첫 화면 사진 (썸네일) | 주제 공고 메인 캡처 | **요약 카드** (숫자) | **사례 현장** 세로 사진 | **비교 카드** (A·B) |
| 첫 문장 | 검색 공감 질문 | **답(숫자) 한 줄** | **결과 장면** | **선택 고민 질문** |
| 소제목 ① | 통념 질문 «~ 아닌가요?» (앞쪽) | «~ N가지» (**맨 앞**) | 사례 질문 «~ 어떻게 됐을까요?» | 비교 질문 «A와 B, 뭐가 다른가요?» |
| 소제목 ② | «~ N가지» (가운데) | 상황 질문 «~면 어떻게 하나요?» (**뒤쪽**) | «~ 되는지 보는 N가지» (**맨 뒤**, 짧게) | «A가 맞는 대표님 N가지» (가운데) |
| 비유 | 1개, 소제목 ① 바로 밑 + 최대 3번 회수 | **없음** (있어도 정리 한 줄) | 1개, **이야기 전환점에 한 번** | 1개, **훅 바로 뒤** (갈림길 자체) |
| 사례 | 세로선 제목 + 썰 (본론) | 제목 없이 2~3줄 상담 장면 하나 | **글 전체가 사례** | 대표님 두 분의 **엇갈린 판정** |
| 숨은 팁 | 구분선 + 전환 문장 + 팁 | 소제목 ② 의 답이 곧 팁 (계산 예시) | **없음** (체크 마지막 항목에 녹임) | «둘 다 놓치는 것» 한 문단 |
| 문단 리듬 | 짧은 줄 연타, 단독 강조 줄 많음 | 2~3줄 설명 문단 고르게, 단독 줄 2개 이하 | 3~4줄 이야기 문단, 단독 줄 1~2개 | **짝 문단** (A는 ~ / B는 ~) |
| 구분선 | 2개 (훅 뒤, 팁 앞) | 1개 (체크 끝) | 0~1개 (마무리 앞) | 2개 (비교 뒤, 판정 뒤) |
| 대표 강조 | `{형}아닙니다.{/}` 단독 | 항목마다 `{큰}숫자{/}` | `> 대표님 말` · `{노}결과{/}` | `{파}A는{/}` ↔ `{파}B는{/}` 대구 |

네 틀 모두 같은 것: 고정 마무리(길라잡이 4-4), «단, ~» 단서, 실적 배너 값, 소제목 2개(독자 질문 또는 «N가지» 꼴), 왼쪽 정렬, 1,200~1,600자.

- 사례를 소제목 ② 앞에 둘지 뒤에 둘지

## 2. 틀 2 «체크리스트» — 답부터, 항목마다 사진

v7 레퍼런스 1(«햇살론») 정보형을 더 밀어붙인 틀이다. **검색 공감 훅·«아닙니다»·약속 문장이 없다.**
첫 화면에 답을 주고, 항목마다 «사진 → 읽어 주기»를 반복한다.

```
[사진 1]                               ← 공고 표 전체 (크롭, 테두리 없음)

○○, 2026년 3분기엔
{큰}연 3.85%부터 5.45%까지{/}입니다.   ← 첫 문장이 답

(누가 봐야 하는지 2줄)
(이 글에서 무엇을 볼지 1줄 — 풀 B 중 «짚어 드릴게요» 계열, 또는 생략)

## ○○ 확인할 N가지                     ← 소제목 ① 이 글 맨 앞쪽

{파}1. 항목{/}

[사진 2]                               ← 그 항목 줄에 빨간 테두리

빨간 테두리 친 칸이 ~예요.             ← 읽어 주기 1줄
(해석 1줄 · 대상 1줄 · 핵심 숫자 {큰})

{파}2. 항목{/}
[사진 3]
…                                      ← 4~5개. 항목마다 사진 1장
{파}5. 이런 경우는 막혀요{/}            ← 마지막 항목은 막히는 경우 ({빨})

[구분선]

## ○○면 어떻게 하나요?                  ← 소제목 ② 자주 틀리는 상황

(답 2문단 + 계산 예시 1줄 = 숨은 팁)
(상담 장면 2~3줄 — 사례 제목 없이 «지난주 오신 대표님도 ~»)

(마무리: 길라잡이 4-4)
```

| 지킬 것 | 이유 |
|---|---|
| 첫 문장에 숫자·결론 | 틀 1·3의 공감 훅과 첫 화면이 달라진다 |
| 항목마다 사진 1장 | «사진-읽어 주기» 반복이 이 틀의 리듬. 정합성도 가장 쉽다 |
| 단독 강조 줄 2개 이하 | 설명 문단 중심 (틀 1의 연타와 달라진다) |
| 비유 쓰지 않음 | 쓰더라도 정리 한 줄 «금리는 날씨 예보처럼 ~» |
| `{큰}` 은 항목마다 1번 | 이 틀의 대표 강조 |

**잘 맞는 주제**: 분기 금리, 자격 요건, 제출 서류, 바우처 사용처, 신청 절차(항목 = 단계).

## 3. 틀 3 «결과부터» — 승인 장면에서 시작해 되감기

글 전체가 사례 하나다. **결과를 첫 화면에 보여 주고**, 어떻게 거기까지 갔는지 되감는다.
틀 1과 같은 사례형이지만 순서가 거꾸로다. 틀 1은 오해 → 비유 → 사례 → 체크, 틀 3은 결과 → 처음 → 전환점 → 체크다.

```
[사진 1]                               ← 사례 현장 (업종 가게·작업장)

지난달 세종에서 한식당 하시는
대표님이 {노}연 3.85% 자금을 받으셨어요.{/}

처음 오셨을 땐 {빨}점심 매출이 반 토막{/},
은행 두 곳에서 거절된 뒤였습니다.

> 매출이 떨어졌는데
> 정책자금이 되겠냐고 하셨어요.         ← 대표님 말 (따옴표 없이)

## 매출이 꺾였는데 어떻게 됐을까요?      ← 소제목 ① 사례가 품은 질문

(되감기 이야기 — 3~4줄 문단 3개)
 · 처음 상황 (업력·규모·무엇이 막혔나)
 · 대표님이 알고 있던 것 / 오해
 · 우리가 공고에서 찾은 것

[사진 2]                               ← 공고 조건, 대표님이 맞은 줄에 테두리

대표님이 맞은 줄이 여기예요.            ← 읽어 주기
(비유 1번 — 전환점. «은행이 건강검진이라면 이 자금은 응급실» 식)

(진행 장면 — 서류·실사, 사진 1~2장)

{노}결과 한 번 더 — 기간·자금 이름{/}  (금액은 대표님이 준 것만)

## 대표님 가게도 되는지 보는 3가지      ← 소제목 ② 맨 뒤, 짧게

{파}1. ~{/} 한 줄
{파}2. ~{/} 한 줄
{파}3. ~{/} 한 줄 — 놓치기 쉬운 것 (숨은 팁 대신)

[구분선]                               ← 0~1개

(마무리: 길라잡이 4-4)
```

| 지킬 것 | 이유 |
|---|---|
| 첫 문장 = 결과 장면 («지난달 ~ 받으셨어요») | 검색 공감 훅(틀 1)과 정반대 출발 |
| 약속 문장·`>` 반전 질문·«아닙니다» 없음 | 틀 1 표지를 쓰지 않는다 |
| 이야기 문단은 3~4줄 | 짧은 연타 대신 흐름 |
| 감정 표현은 대표님 말에 1~2회 | v7 사례 규칙 |
| 체크는 항목당 1~2줄 | 본론은 이야기, 체크는 덧붙임 |
| 숨은 팁 전환 문장(«손해 보는 부분이 하나 더») 쓰지 않음 | 체크 3번에 녹인다 |

**잘 맞는 주제**: 긴급경영안정자금, 대환대출, 상환연장, 재도전 자금. 사례 한 건이 곧 제도 설명인 것.

## 4. 틀 4 «갈림길» — 둘을 나란히 놓고 고르게 하기

비슷한 두 제도·두 방식을 **짝 문단**으로 나란히 비교하고, «어느 쪽이 맞는 대표님인지» 판정 기준을 준다.

```
[사진 1]                               ← 두 제도가 함께 보이는 화면 (금리표 두 줄에 테두리 2개 등)

혁신성장촉진자금과 일반경영안정자금,
둘 다 소진공 자금인데
{노}어느 쪽을 신청해야 할까요?{/}       ← 선택 고민 훅

(잘못 고르면 생기는 일 1~2줄 {빨})

(비유 1번 — 갈림길 자체. «같은 노선의 일반열차와 급행열차» 식)

## 혁신성장자금과 일반자금, 뭐가 다른가요?  ← 소제목 ① 비교 질문

{파}혁신성장자금은{/} ~                 ← 짝 문단 1: 대상
{파}일반자금은{/} ~

[사진 2]                               ← 그 차이가 적힌 공고 (테두리 2개)

{파}혁신성장자금은{/} ~                 ← 짝 문단 2: 금리·한도
{파}일반자금은{/} ~

[사진 3]

(짝 문단 3: 심사 방식 · 서류)

[구분선]

## 혁신성장자금이 맞는 대표님 3가지     ← 소제목 ② 판정 기준

{파}1.{/} ~ / {파}2.{/} ~ / {파}3.{/} ~

(판정 예시 두 분 — 결론이 다르게)
청주 공방 대표님은 ~라서 {파}혁신성장자금{/},
대전 카페 대표님은 ~라서 {파}일반자금{/}이 맞았어요.

[구분선]

(둘 다 놓치는 것 한 문단 — 숨은 팁 자리)

(마무리: 길라잡이 4-4)
```

| 지킬 것 | 이유 |
|---|---|
| 짝 문단은 앞 단어를 맞춘다 (`{파}A는{/}` / `{파}B는{/}`) | 이 틀의 리듬이자 대표 강조 |
| 짝 하나마다 사진 1장 | 비교가 사진에 보이게 |
| 판정 예시는 결론이 **다른** 두 분 | 한쪽 홍보로 안 보인다 |
| 다른 업체·은행 상품 비교 ✗ | 표시광고법. 비교 대상은 **공공 제도끼리만** |
| 표(`\|`) 는 쓰지 않는다 | 붙여넣기에서 표가 살아남는지 미확인 |

**잘 맞는 주제**: 직접대출 vs 대리대출, 혁신성장자금 vs 일반경영안정자금, 상환연장 vs 대환대출, 변동 vs 고정금리, 바우처 vs 정책자금.

## 5. 문구 풀 — 매번 같은 문장을 쓰지 않는다

같은 자리에 늘 같은 문장이 오면 틀이 달라도 닮아 보인다. 자리마다 아래에서 고르고, **직전 3편에 쓴 문구는 쓰지 않는다.**
`scripts/유사도검사.py` 가 같은 문장을 잡는다.

**A. 첫 줄** (틀이 정한 종류 안에서 고른다)

| 종류 | 예 |
|---|---|
| 검색 공감 (틀 1) | «대표님, ○○ 검색해서 들어오셨나요?» · «○○ 알아보다가 여기까지 오셨죠?» · «○○ 때문에 밤에 검색창 여셨나요?» |
| 답 먼저 (틀 2) | «○○, 지금은 ~입니다.» · «결론부터 말씀드리면 ~예요.» · «2026년 ○분기 ○○는 ~까지입니다.» |
| 결과 장면 (틀 3) | «지난달 ○○ 대표님이 ~ 받으셨어요.» · «석 달 전만 해도 ~이던 가게가 ~» · «서류를 다시 쓰고 3주 만에 ~» |
| 선택 고민 (틀 4) | «A와 B, 어느 쪽을 신청해야 할까요?» · «둘 다 연 ○%대인데 뭐가 다를까요?» · «A로 갈지 B로 갈지 상담에서 가장 많이 받는 질문이에요.» |

**B. 약속** (틀 1에서만 필수, 틀 2는 선택, 틀 3·4는 쓰지 않는다)
«이 글 끝까지 보시면 3분 안에 ~» · «오늘은 ~만 짚어 드릴게요.» · «읽고 나시면 ~는 바로 구분하실 거예요.» · «~ N가지만 보시면 됩니다.»

**C. 숨은 팁 전환** (틀 1·4)
«여기서 확인하고 바로 신청하시면 손해 보는 부분이 하나 더 있습니다.» · «그런데 여기서 한 번 더 놓치세요.» · «신청서 쓰기 전에 하나만 더 보세요.» · «조건이 맞아도 이걸 모르면 손해예요.»

**D. 정리 신호**
«정리하면 이렇습니다.» · «한 줄로 줄이면» · «결국 핵심은 하나예요.» · «기억하실 건 이것 하나입니다.» · (없이 바로 마무리)

**E. 실적 문장** — 숫자는 배너 그대로, 문장은 바꾼다
«누적 컨설팅 5,600건, 자금 승인율 97.2%입니다.» · «5,600건을 상담하며 가장 많이 본 실수가 ~» · «승인율 97.2%도 결국 ~를 먼저 본 덕분이에요.» · «누적 승인 금액 572억+ 가운데에도 ~ 대표님이 많았습니다.»

**F. 손실 회피** (마무리 맨 앞)
«~하고 멈춰 계시면 ~ 놓칠 수 있어요.» · «~를 모르고 신청하면 ~부터 다시 해야 합니다.» · «지난 분기 기준으로 고르면 ~» · «혼자 서류를 넣었다가 ~»

**G. 단서 «단, ~»** (필수, 문장은 바꾼다)
«단, 금리는 분기마다 바뀌니 ~» · «단, 예산이 소진되면 ~ 마감됩니다.» · «단, 공고 조건은 해마다 달라지니 ~» · «단, 지역 센터마다 접수 일정이 달라요.»

고정이라 바꾸지 않는 것: «혹시 ~ 고민이시면 ~부터 한번 같이 봐요», 고정 2블록, 네이버폼 주소.

## 6. 돌려 쓰는 법 (로테이션)

| 규칙 | |
|---|---|
| 이웃한 두 글은 **다른 틀** | 주를 넘어가도 (지난주 7번 ↔ 이번 주 1번) |
| 한 주 7편에 같은 틀 **최대 2편** | 7 = 2 + 2 + 2 + 1 |
| 같은 틀을 다시 쓸 때 **다이얼 3개 이상** 다르게 | 첫 줄 종류 안의 문장 · 약속 · 비유 소재 · 사례 지역·업종 · 정리 신호 · 사진 첫 장 종류 · 제목 형식 |
| 유형 균형은 저절로 맞는다 | 틀 1·3 = 사례형, 틀 2·4 = 정보형 → 주 7편이면 3~4 : 3~4 |
| 주제가 틀을 고른다 | 0번 표 «이런 주제에». 맞는 틀이 이미 2편이면 주제를 바꾼다 |

배치 예 (한 주): `2 → 1 → 4 → 3 → 2 → 4 → 3`
다음 주는 지난주 마지막(3)과 다른 틀로 시작한다.

## 8. 이미지 설계 — 틀마다 고유한 느낌

글 구조가 달라도 사진 구성이 같으면 똑같아 보인다. 1006 7편이 그랬다.
- 2번 사진이 5편 연속 소진공 로고였다
- 박성제 대표·상담사 사진이 4편, 같은 배너가 3편에 들어갔다

그래서 이미지도 틀마다 따로 설계한다. 정하는 것은 다섯 가지다.

| 정하는 것 | 내용 |
|---|---|
| 장수 | 몇 장 쓰나 |
| 비율 | 가로냐 세로냐 |
| 첫 장 | 썸네일이 될 사진 |
| 공고 캡처 처리법 | 테두리·번호·확대 중 무엇으로 짚나 |
| 정보 카드 | 우리가 직접 만드는 이미지 |

### 8-0. 정보 카드 — 우리가 만드는 이미지

`scripts/카드.py` 로 만든다. 견본 12장은 `docs/구조틀_견본/_한눈에.jpg`.

카드는 **종류 4 × 디자인 3 × 글자 배치 3 × 내용 테마 7** 로 만든다. 같은 종류가 반복돼도 폼과 색이 달라진다 (대표님 10-12 «글자만 다르고 폼이 다 비슷하다»).

| 종류 | 틀 | A | B | C |
|---|---|---|---|---|
| **반전** | 1 | 짙은 바탕 · 취소선 · 테두리 도장 | **사진 배경**(어둡게) · 가운데 · 빨간 알약 | **줄노트 종이** · 마커 취소선 · 기울어진 도장 |
| **요약** | 2 | 흰 바탕 · 색 머리 · 줄무늬 표 | **그라데이션 포스터** · 반투명 칩 2열 | **영수증** · 점선 · 톱니 가장자리 |
| **타임라인** | 3 | 종이 · 명조 · 세로 줄 | 연한 그라데이션 · **흰 카드 쌓기** · 번호 배지 | **사진 머리 다이어리** |
| **비교** | 4 | 흰 바탕 · 두 칸 표 | **좌우 색 분할 · VS** | **떠 있는 카드 두 장** · «같은 점» 띠 |

**글자 배치 (배치 1·2·3)** — 디자인마다 글자가 놓이는 자리와 구조가 다르다 (대표님 10-12 «같은 위치에 같은 구조라 중복된 글처럼 보인다»).
견본 36장: `docs/구조틀_견본/_배치_반전.jpg` · `_배치_요약.jpg` · `_배치_타임라인.jpg` · `_배치_비교.jpg`

| 종류 | 배치 1 | 배치 2 | 배치 3 |
|---|---|---|---|
| 반전 | 왼쪽 위부터 쌓기 | 가운데 정렬 · 세로 가운데 | 위(통념)·아래(결론, 오른쪽 정렬) 나눔 |
| 요약 | 숫자 먼저 → 표 | 표 먼저 → «그래서 결론은» 숫자 상자 | 숫자가 주인공(아주 크게) → 표는 2~3열로 작게 (영수증은 기울임) |
| 타임라인 | A 왼쪽 세로줄 · B 꽉 찬 카드 · C 사진 머리 | A 지그재그 · B 좌우 엇갈림 · C 사진 왼쪽 띠 | A 큰 번호 열 · B 2열 격자 · C 둥근 사진 + 가운데 제목 |
| 비교 | A 좌우 칸 · B 좌우 분할 VS · C 카드 나란히 | A 항목마다 위아래 · B 위아래 분할 · C 카드 위아래 | A 묶음→B 묶음 · B 왼쪽 항목 띠 · C 왼쪽 색 막대 + «같은 점» 위 |

**자동 장치 세 가지** — 카드.json 에 적지 않으면 도구가 고른다

1. **테마(배경색) = 내용에 맞게.** 카드 제목을 먼저 읽고 낱말로 고른다. 제목에서 안 잡히면 나머지 글을 본다

   | 테마 | 이런 낱말 | 색 |
   |---|---|---|
   | 재기 | 재도전·재창업·폐업·다시 연 | 주황 → 보라 새벽빛 |
   | 복지 | 장애인·복지·국가유공자 | 세이지 녹색 |
   | 주의 | 제한·체납·연체·막히·못 받 | 짙은 빨강·검정 |
   | 제조 | 제조·공방·설비·시설자금·소공인 | 나무 갈색 |
   | 가게 | 반찬·식당·국수·가게·마트·카페·미용실 | 테라코타·크림 |
   | 금리 | 금리·이자·우대·분기 | 남색 |
   | 기본 | 위에 없음 | 청록 |

2. **디자인(A·B·C) = 최근과 다르게.** 같은 종류 카드가 최근 3번 쓴 디자인은 건너뛴다
3. **배치(1·2·3) = 최근과 다르게.** 같은 종류 카드가 최근 3번 쓴 배치는 건너뛴다.
   기록은 `출력/카드기록.json` (폴더 · 종류 · 디자인 · 배치 · 테마)에 저절로 쌓인다

- 사진 배경 디자인(반전 B · 타임라인 C)은 `"photo"` 로 **그 글 본문에 쓰지 않은 사진**을 준다. 없으면 그 디자인은 건너뛴다
- 비교 카드의 청록·보라는 공고 캡처 테두리(`box_color`)와 짝이라 테마와 상관없이 고정. 배경과 구성만 바뀐다
- 직접 정하고 싶으면 카드.json 에 `"style": "B"`, `"layout": 2`, `"theme": "복지"` 를 적는다

왜 쓰나:
- 저작권 걱정이 없다. AI 생성이 아니라 공고 숫자를 우리가 디자인한 그림이다
- 네이버가 가산점을 주는 **독자 이미지**가 된다
- 틀의 얼굴이 된다

지킬 것:
- 숫자·조건은 **공고 원문 그대로**
- 사례 카드(타임라인)는 글 속 사례와 같은 내용만, 승인 금액은 대표님이 준 것만
- 카드는 **글당 1~2장.** 카드만 늘리면 그게 또 양산형이다

### 8-1. 틀 1 «뒤집기» — 대비

| 항목 | 값 |
|---|---|
| 장수 | 8~10장 |
| 비율 | **가로 3:2 위주** (카드만 정사각) |
| 첫 장 | 주제 공고 메인 캡처 (가로, 제목부, 테두리 없이) |
| 캡처 처리 | **빨간 테두리** (`boxes`) — 이 틀의 표지 |
| 스톡 성격 | **넓은 장면** (와이드 샷). 비유 연출 1장 + 사례 현장 1~2장 |
| 카드 | 반전 카드 1장 — 소제목 ① 의 «아닙니다» 자리 |
| 브랜드 | 배너(그 문구를 옆 문단이 말할 때) 또는 대표·상담사 |

순서 예: `공고 메인 → 비유 장면 → [소제목①] 반전 카드 → 사례 현장 → [소제목②] 공고 테두리 ×2 → 진행 공고 → 팁 공고 → 브랜드`

### 8-2. 틀 2 «체크리스트» — 자료집

| 항목 | 값 |
|---|---|
| 장수 | **9~12장 (가장 많다)** |
| 비율 | **세로 4:5 위주** |
| 첫 장 | **요약 카드** (썸네일이 숫자 카드) |
| 캡처 처리 | **확대 크롭 + 노란 형광펜 + 남색 번호 원** (`marks` + `badges`). 번호는 체크 항목 번호와 같게. 빨간 테두리는 쓰지 않는다 |
| 스톡 성격 | **사물 정물, 사람 없음** (계산기·서류·달력·카드·통장). 1~2장 |
| 카드 | 요약 카드 1장 (첫 장) |
| 브랜드 | 프로필카드 또는 네이버플레이스 (전문성) |

순서 예: `요약 카드 → [소제목①] ① 확대 → ② 확대 → 정물 → ③ 확대 → ④ 확대 → ⑤ 막히는 경우 확대 → [소제목②] 정물 → 브랜드`

### 8-3. 틀 3 «결과부터» — 다큐

| 항목 | 값 |
|---|---|
| 장수 | **7~9장 (가장 적다)** — 이야기 문단이 길어 사진 간격이 넓다 |
| 비율 | **세로 2:3 위주**, 따뜻한 자연광 톤 |
| 첫 장 | **사례 현장 세로 사진.** 얼굴보다 손·뒷모습·공간 |
| 캡처 처리 | **최소 1~2장**, 대표님이 맞은 줄에 `labels` 한 개(«여기») |
| 스톡 성격 | **같은 업종의 다른 컷 3~4장.** 공간 → 손 클로즈업 → 서류 정리 → 다시 공간. 한 가게를 따라가는 느낌 |
| 카드 | 타임라인 카드 1장 — 되감기가 끝나고 결과를 다시 말하는 자리 |
| 브랜드 | 대표·상담사 또는 박성제 인물컷 (사람 냄새) |

순서 예: `현장 공간 → [소제목①] 손 클로즈업 → 공고 «여기» → 서류 정리 컷 → 타임라인 카드 → [소제목②] 현장 다른 컷 → 브랜드`

### 8-4. 틀 4 «갈림길» — 대칭

| 항목 | 값 |
|---|---|
| 장수 | 8~10장 |
| 비율 | **가로 위주, 짝으로 연속** (A 사진 바로 다음 B 사진) |
| 첫 장 | **비교 카드** (가로) |
| 캡처 처리 | **짝 캡처** — A 공고와 B 공고를 같은 폭으로 잘라 연속 배치. 테두리는 카드와 같은 색: A 청록 `#13806e` · B 보라 `#5b3fa0` (`box_color`) |
| 스톡 성격 | 비유 연출 1장(두 갈래 길·두 개의 선택지) + 판정 예시 **업종 짝** 1쌍(같은 구도, 다른 업종) |
| 카드 | 비교 카드 1장 (첫 장) |
| 브랜드 | 성제관 유튜브채널 또는 한비즈마케팅 팀배너 |

순서 예: `비교 카드 → 갈림길 비유 → [소제목①] A 공고 → B 공고 → A 공고 → B 공고 → [소제목②] 업종 A → 업종 B → 브랜드`

### 8-5. 반복 금지 (모든 틀)

| 무엇 | 규칙 |
|---|---|
| 스톡 사진·카드 | **다시 쓰지 않는다** (모든 글 통틀어) |

### 8-6. 스톡 검색어 — 문장 + 틀의 톤

검색어는 그 사진 옆 문장으로 만든다(정합성). 거기에 틀의 톤을 붙인다. 사람·가게는 `korean` 을 앞에 붙인다.

| 틀 | 붙이는 말 | 예 |
|---|---|---|
| 1 | `wide`, `interior`, `street` | korean restaurant interior wide |
| 2 | `flat lay`, `minimal`, `desk`, `top view` | calculator documents flat lay minimal |
| 3 | `warm light`, `hands`, `close up`, `vertical` | korean bakery hands close up warm light |
| 4 | `two`, `choice`, `crossroads`, 같은 구도 짝 | crossroads two paths / korean cafe counter + korean salon counter |
