# 블로그 구조 레퍼런스 2 — 매출 없는 사업자 대출(신규사업자 정책자금) (사장님 10-06, 이미지 16장)

제목(질문형 두 문장 + 반전): «엥? 매출 없는 사업자도 대출 가능한가요? 신규사업자도 가능! 정책자금 1억도 가능한데요?» · 카테고리 «정책자금 노하우»

1. 데이터 이미지(매출 하락 그래프) → 공감(노랑 배경): 매출은 없는데 돈은 필요하시죠? 안 될 걸 알면서 알아보다 이 글 보게 되셨을 것
2. 데이터 이미지(신규 창업 수) → 대상 지정: 신규 창업했거나 매출 없어 힘든데 돈 필요한 대표님이라면 이 글 진짜 중요
3. 은행 로고 모음 → 공감(노랑): 운영자금 막혀 1금융 거절당한 분 정말 많이 봤다
4. 글 목적 + 약속(이탤릭·밑줄·노랑): 끝까지 보시면 왜 가능한지 3분 안에 정리
5. 현실 이미지(폐업 점포 뉴스 사진)
6. 인용구 소제목 = 독자 질문: «매출 없으면 사업자대출 못 받는 거 아닌가요?»
7. 비유 연출 사진(신입사원) → «절대 아닙니다.» + 비유(노랑): 매출없는 사업자대출 = 이력서 없는 신입사원 채용 / 은행 일반 대출 = 경력직 채용(빨강) → 매출·재무제표 보는 자리
8. 비유 일러스트(창업 2달 차) → 대비(빨강): 등록 2달 차가 경력직 자리 가면 떨어짐 → 정책자금+신보 = 신입공채 → 핵심(노랑): 지금 매출이 아니라 앞으로 어떻게 굴러갈지
9. 자사 유튜브 썸네일 4장 → 신뢰: «누적 승인률 97% 중에도 신규·매출 없는 케이스 많았다»
10. 세로선 인용 사례 제목: «대전 테크노단지 제조업 대표님께 한 달 만에 1억 가까이 받아드린 썰»
11. 비유 연결 이미지(대기업 공채 속보, 흐림) → «신입공채 예시로 대출 때 뭘 보는지 풀어드리겠다»(노랑)
12. 사례: 공장 사진 → 작년, 대전, 막 차린 제조업, 등록 2달, 매출 0 → 상황(빨강): 본인 돈으로 공사, 운영자금 한 달 치도 없음
13. 은행 로고 → 1금융 다섯 군데 다 거절(빨강) → 자포자기(노랑, ㅠㅠ)
14. 감정 사진(화난 여성) → 가운데 인용(대표님 말): «매출도 없는데 신규사업자대출이 가능하겠냐고»
15. 비유 회수: 일반 은행은 경력직 자리 → 기관 로고(신용보증재단) → 신보는 신입공채 따로, 사업 구조·자금 계획을 본다
16. 문서 이미지(사업계획서, 흐림) → 해결(노랑): 사업계획서 처음부터 다시 — 고객 유입 경로, 객단가, 운영자금 쓸 자리
17. 달력 이미지 → 결과(노랑, 느낌표 4개): 2달도 안 돼 신보 보증서 + 일반경영안정자금 묶어 1억 가까이 승인
18. 소제목(구분선): «매출 대신 평가자가 보는 심사 조건 4가지» → «보는 건 정해져 있습니다»(노랑) → 1~4 파란 글자 항목(돈이 들어오는 구조 / 자금 사용 계획 / 대표자 준비도 / 기본 신용) 각 1~2줄
19. 예능 짤(«이제 거지예요») → 정리(노랑): 매출없는 사업자대출은 이력서 없는 신입사원 채용 → 핵심: 매출 없는 게 문제가 아니라 사업 구조가 설명되는지
20. 예능 짤(«안 맞는 것 같아요… 싫어요!») → 손실 회피 CTA(노랑): 거절당하고 멈춰 계시면 금방 말씀드린 대표님처럼 → 성공사례 모음 이미지 → 30분이면 무료 확인 → 네이버폼(밑줄) → 시기(노랑): 연말엔 한도가 작아져 힘든 경우 많다, 지금이 가장 빠를 때
