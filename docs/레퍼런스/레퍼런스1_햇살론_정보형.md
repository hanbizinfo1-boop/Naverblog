# 블로그 구조 레퍼런스 1 — 햇살론 일반보증 (사장님 10-06, 이미지 9장)

사장님: «블로그 구조는 이런 식으로 잡아줘, 나머지 하나 더 보내줄 테니 다음 거까지 확인하고 구조 잡아줘» → 레퍼런스 2 받은 뒤 합쳐서 구조 확정.

## 흐름
1. 도입 이미지: 네이버 검색 결과 캡처(햇살론 검색 → 서민금융대출 카드) — 검색해서 들어온 사람과 바로 맞춤
2. 공감 훅: «대표님, 햇살론 검색해서 들어오셨나요?» → «신용점수 때문에 한 번쯤 거절당해 보신 분»
3. 감정 이미지(캐릭터·밈)
4. 상황 나열 3줄: 1금융 거절 → 2금융도 안 됨 → 대부업 광고
5. 반전 질문(하늘색 배경): «근데 거절당한 진짜 이유가 신용점수가 맞을까요?»
6. 약속: «이 글 끝까지 보시면 3분 안에 [자격 4가지](노랑) + 대부분 놓치는 [보증료 깎는 법](빨강)»
7. 구분선 → 대표 이미지(상품 로고)
8. 인용구 소제목 = 독자 질문: «신용점수 낮으면 … 안 되는 거 아닌가요?»
9. 짧은 답 «아닙니다.» → 비유(잠깐 빌려 쓰는 우산) → 정의(대상 파랑·기관 밑줄 링크·«정부 지원 대출» 빨강) → 최신 변경(2026 통합)
10. 기관 로고 이미지(서민금융진흥원)
11. 번호 소제목(살구 배경) 1~4 자격: 조건(숫자 빨강) + 한 줄 해석 + 대상 예시(파랑 밑줄)
12. 경고: 예능 짤(«이 사기꾼») + «정부 보증 상품이라 먼저 카톡 접근 없음» + 사기업체 주의
13. 구분선 → 다음 훅 «여기서 바로 신청하시면 손해 보는 부분이 하나 더»
14. 숫자 정보(한도·금리, 빨강) + 개념 이미지(3D 금리 하락) + 개편 내용 + 상환 방식(장점 하늘색)
15. 숨은 팁(보증료): 비용 계산 예시(1,200만 원 → 연 30만 원) → 깎는 법(앱 이미지) → 조건별 인하폭(하늘색) → 경고 «신청 후엔 못 깎습니다»(빨강) → 덤(중도상환수수료 0원)
16. CTA: «자격 4가지 구분 어려우시면 아래 네이버 폼 → 저 박관장이 1:1 진단»

## 형식
- 한 줄 1문장(길면 2줄로 끊음), 생각 단위마다 빈 줄. 구분선으로 큰 단락 3개(훅 / 자격 / 돈 아끼는 팁)
- 색 규칙: 빨강 글자 = 핵심 숫자·경고 · 노랑 배경 = 핵심 개념·약속 · 하늘 배경 = 반전 질문·장점 · 파랑 글자(밑줄) = 대상·기관 링크 · 살구 배경 = 번호 소제목 · 밑줄 = 행동 문장
- 이미지 7장: 검색 캡처 · 감정 밈 · 대표 로고 · 기관 로고 · 경고 짤 · 개념 3D · 앱 화면(캡션)
- 소제목은 «독자가 할 질문»을 인용구로, 답은 첫 줄에 짧게
- 화자 = «저 박관장», 독자 = «대표님»
