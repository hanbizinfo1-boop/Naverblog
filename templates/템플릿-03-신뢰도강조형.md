# 템플릿 03 — 신뢰도 강조형

출처 샘플: 사업계획서로 정책자금 승인받기

이 문서 하나만 보고 글을 쓸 수 있도록 자체 완결로 작성한다. 다른 템플릿을 참조하지 않는다.

---

## 1. 글 구조 (이 순서 그대로)

| 순서 | 요소 | 분량 |
|------|------|------|
| 1 | **기관 간판 실사 이미지** | 1컷 |
| 2 | 훅 — 대비 선언 (형광펜, 마침표 없음) | 2줄 |
| 3 | 원인 지목 (빨강, 마침표 없음) | 2줄 |
| 4 | **카드뉴스 이미지** — 실패 이유 5가지 | 1컷 |
| 5 | **용어 정의 블록** (형광펜 2줄) | 2줄 |
| 6 | 사례 도입 — 지역 + 업종 | 3줄 |
| 7 | **밈 이미지** | 1컷 |
| 8 | 사례 진단 | 4줄 |
| 9 | **소제목 첫째** → **프로필 배너** → 본문 + **불릿** → **이미지** → 본문 | 본문 10~12줄 |
| 10 | **소제목 둘째** → **실적 배너** → 본문 → **브랜드 배너** → 본문 | 본문 12~14줄 |
| 11 | **소제목 셋째** → **기관 간판** → 본문 + **불릿** → **기관 간판** → 본문 | 본문 12~14줄 |
| 12 | **유튜브 썸네일 그리드** | 1개 |
| 13 | 사례 결과 | 5줄 |
| 14 | **브랜드 배너** | 1컷 |
| 15 | 사례 해석 | 4줄 |
| 16 | 요약 — 불릿 3개 | 4줄 |
| 17 | **대표 + 상담사 프로필 이미지** | 1컷 |
| 18 | 마무리 선언 | 2줄 |
| 19 | 회사 소개 + CTA | 8줄 |

이미지 총 약 12컷. **가장 고밀도.** 소제목 구간마다 2컷씩 들어간다.

---

## 2. 줄 규격

- 한 줄 **8~28자** (공백 포함). 최빈 14~25자.
- 의미 단위로 자른다.
- **마침표를 자주 생략한다. 이 템플릿의 특징이다.**
  - 호흡이 다음 줄로 **이어지면 생략**
    `같은 조건인데 한 분은 되고` / `견적서나 계약서가 있으면 같이 붙이십시오`
  - 단락이 **끊기면 마침표**
    `이 돈을 갚을 수 있는지 판단하는 근거입니다.`
  - 절대 규칙은 아니다. 혼용하되 생략 쪽이 더 많다.

## 3. 문단 규격

- 한 문단 **1~3줄**. 4줄 이상 금지.
- 문단 사이 빈 줄 **1개**.
- 소제목 앞뒤는 빈 줄 **2개 이상**.

---

## 4. 소제목

- 개수: **정확히 3개**
- 형식: `첫째. 자금 용도를 숫자로 쪼개십시오.`
  - **첫째 / 둘째 / 셋째** + 마침표 + 공백. **아라비아 숫자를 쓰지 않는다.**
  - 문장형 + `~하십시오` 명령 종결 + 마침표
  - 길이 14~20자
- 표시: 좌측 세로 막대 + 볼드

---

## 5. 불릿 리스트 (이 템플릿의 핵심 장치)

```
• 원재료 얼마
• 인건비 얼마
• 설비 얼마
```

- 가운뎃점 `•` 사용.
- **항목마다 형광펜을 칠한다.**
- 3~5개 항목.
- 각 항목은 **10자 이내 짧은 명사구**. 문장으로 쓰지 않는다.
- 마침표 없음.
- 소제목 본문 안에 2회, 마무리 요약에 1회 쓴다.

---

## 6. 강조

| 방식 | 쓰는 곳 |
|------|--------|
| 주황·노랑 형광펜 | 훅, 용어 정의, 불릿 항목, 결과 선언 |
| 빨강 글씨 | 핵심 주장, 판정 문장 |
| 볼드 | 소제목 |

- **형광펜 비중이 가장 높다.** 빨강 글씨보다 형광펜을 더 많이 쓴다.
- 구절 단위로도 칠한다.
- **파랑 형광펜·이탤릭은 쓰지 않는다.**

---

## 7. 이미지 명세

12컷 중 **8컷이 생성 불가**다. 기존 자산을 받아 재사용해야 한다.

### 생성 불가 — 브랜드 고정자산 (5컷)

| 자산 | 내용 |
|------|------|
| 대표 프로필 카드 | 박성제 / 자격증 4종 / 수상 경력 |
| 실적 배너 | 승인건수 5,600+ / 승인율 97.2% / 누적 572억+ |
| 전화번호 배너 A | "실제로 승인까지 이어진 이유" + T.1555-2028 |
| 전화번호 배너 B | "안 되는 조건이 아니라 맞는 틀을 찾았습니다" + T.1555-2028 |
| 상담사 프로필 | 대표 + 상담사 6인 |

### 생성 불가 — 기관 실사 (3컷)

SGI서울보증 / 소상공인시장진흥공단 / KFME 소상공인연합회 간판.
실제 로고·건물이므로 생성하면 허위가 된다. 직접 촬영본 또는 보유 자산을 쓴다.

### 생성 가능 (3~4컷)

| # | 성격 | 비율 |
|---|------|------|
| 1 | 카드뉴스 — 실패 이유 5가지 불릿 | 세로 |
| 2 | 밈·짤 — 좌절 표정 | 가로 |
| 3 | 개념 이미지 (로봇·추상) | 가로 |

### 기타

- 유튜브 썸네일 4개 그리드는 실제 영상 임베드다. 이미지가 아니다.
- 배너류는 세로형, 실사·밈은 가로형.
- 전부 좌측 정렬.

## 8. 사례 규격

- 지역명 + 업종 (예: 대전 인테리어업).
- 호칭은 `대표님`.
- **실패 → 진단 → 교정 → 승인** 순서.
- 진단 대사를 서술로 처리한다.
  `저는 이건 계획서가 아니라 / 각오라고 말씀드렸습니다.`
- 결과는 담백하게.
  `그다음 회차에 정책자금 승인을 받으셨습니다.`

## 10. 금지

- 인용부호 `" "` 금지.
- 이모지 금지.
- 마크다운 기호 금지.
- 4줄 이상 문단 금지.
- **아라비아 숫자 소제목 금지** (첫째/둘째/셋째만).
- **브랜드 자산·기관 간판을 생성해서 채우지 않는다.** 반드시 실제 자산을 쓴다.
