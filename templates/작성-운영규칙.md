# 작성 운영 규칙

`블로그 작성해줘` 요청이 들어왔을 때 **무엇을 어떻게 내놓을지**를 정한 문서다.
글의 형식 규격은 각 템플릿 문서에 있다. 이 문서는 산출물과 이미지 조달만 다룬다.

---

## 1. 산출물 구조

글 1편당 폴더 하나를 만든다. **폴더명은 `MMDD-N`** — 작업한 날짜 + 그날의 순번.

```
출력/
  ├─ 0921-1/
  │    ├─ 포스팅.txt
  │    └─ 이미지/
  │         ├─ 사진1.jpg
  │         ├─ 사진2.jpg
  │         └─ ...
  ├─ 0921-2/
  ├─ 0921-3/
  ...
  └─ 0928-1/
```

- 주 7편 기준이라 같은 날짜에 여러 폴더가 생긴다. 순번은 **1부터** 붙인다.
- 날짜는 **작업한 날**이지 발행일이 아니다. 발행일은 `_publish-log.md` 가 따로 관리한다.
- 폴더명에 주제를 넣지 않는다. 짧아야 탐색기에서 한눈에 정렬된다.
  어떤 글인지는 각 폴더의 `포스팅.txt` 첫 줄(제목)과 `_publish-log.md` 로 확인한다.

- 본문은 **`.txt`** 로 낸다. 메모장에서 열어 네이버 에디터에 그대로 붙일 수 있어야 한다.
- 인코딩 **UTF-8 (BOM 없음)**, 줄바꿈 **CRLF**.
  (메모장에서 열 것이므로 이 파일만 예외적으로 CRLF 를 쓴다)
- 이미지는 하위 폴더 `이미지/` 에 넣는다.

## 2. 사진 번호 매칭 규칙

**본문의 `(사진1)` 과 파일 `사진1.jpg` 가 1:1로 대응한다.**

본문 표기:
```
정책자금 심사도 똑같습니다.

(사진1)

정책자금이란
국가가 정한 요건을 통과한 사업자에게
낮은 금리로 빌려주는 자금입니다.

(사진2)
```

규칙:
- 표기는 `(사진N)` 한 가지만 쓴다. `[사진1]` `사진 1` 같은 변형을 섞지 않는다.
- **자기 줄에 단독으로** 놓는다. 문장 안에 끼워 넣지 않는다.
- 앞뒤로 빈 줄 1개씩.
- 번호는 **1부터 빠짐없이 순서대로**. 중간 번호를 건너뛰지 않는다.
- 파일명은 `사진1.jpg` 형식. **한 자리 숫자에 0을 붙이지 않는다** (`사진01` 아님).
  탐색기 정렬이 10번부터 어긋나므로, **사진이 10컷을 넘으면** 그때만
  `사진01 ~ 사진12` 로 전체를 두 자리로 통일한다. 섞어 쓰지 않는다.
- 확장자는 원본을 따른다 (`.jpg` / `.png`). 본문에는 확장자를 적지 않는다.

### 본문 맨 끝에 대조표를 붙인다

붙여넣기 할 때 헷갈리지 않도록, 본문 마지막에 구분선과 함께 목록을 넣는다.
네이버에 붙일 때는 이 아래를 지우면 된다.

```
────────── 아래는 붙여넣기 전 삭제 ──────────

사진 목록
사진1 — 폐업 정리 중인 매장 내부
사진2 — 대출 상환 고지서 클로즈업
사진3 — 조건 인포그래픽 (제작)
사진4 — 소상공인시장진흥공단 로고 ★고정자산 직접 넣으세요
```

- 고정자산이라 내가 못 넣은 자리는 **`★고정자산 직접 넣으세요`** 로 표시한다.
  그 번호의 파일은 비워두지 말고, 자리표시 텍스트 파일도 만들지 않는다.
  **번호만 비우고 대조표에 사유를 적는다.**

## 3. 이미지 조달

세 갈래로 나뉜다. 순서대로 판단한다.

### ① 무료 스톡에서 가져온다

> ⚠️ **2026-09-21 확인: 자동 조달이 막혀 있다.**
> Unsplash 는 봇 차단 페이지를 반환하고, Pexels 검색 페이지는 이미지 URL 을 내주지 않는다.
> 따라서 **현재 기본 경로는 ② 생성**이다. 아래는 대표님이 직접 받아 주실 때의 허용 출처다.

허용 출처만 쓴다. 전부 상업적 이용·수정이 가능하고 출처 표기 의무가 없는 곳이다.

| 출처 | 주소 | 비고 |
|------|------|------|
| Unsplash | unsplash.com | 사진. 품질 높음 |
| Pexels | pexels.com | 사진·영상 |
| Pixabay | pixabay.com | 사진·일러스트·벡터 |
| 공유마당 | gongu.copyright.or.kr | 한국저작권위원회. 한국적 소재에 강함 |

- **위 네 곳 밖에서 이미지를 가져오지 않는다.** 검색해서 나온 아무 이미지나 쓰면 저작권 침해다.
- 다운로드 시 **출처와 라이선스를 대조표에 남기지 않아도 되지만**, 위 출처가 아니면 쓰지 않는다.
- 사람 얼굴이 크게 나온 컷은 피한다. 초상권 시비가 없는 출처라도 한국인이 아닌 얼굴이
  한국 소상공인 글에 들어가면 이질감이 크다. **사물·손·뒷모습·매장 전경**을 우선한다.

### ② 생성한다 (현재 기본 경로)

Codex 내장 image_gen 을 쓴다. 구독 한도 안에서 돌아 추가 과금이 없다.

생성 이미지는 스톡보다 유리한 면이 있다. 스톡 감점의 이유는 **다른 블로그와 같은 사진**이
쓰이기 때문인데, 생성 이미지는 이 세상에 그 한 장뿐이라 중복이 없다.
다만 직접 촬영 실사의 가산점에는 못 미친다. 순위는 **직접 촬영 > 생성 > 스톡** 이다.

- portrait 1024×1536 / landscape 1536×1024
- 생성 이미지에 **한글 텍스트를 넣지 않는다.** 깨진 글자가 나온다.
  텍스트가 필요한 인포그래픽은 도형·아이콘만 생성하고 글자는 따로 얹거나,
  아예 스톡 + 본문 설명으로 대체한다.

### ③ 고정자산 — 내가 만들지 않는다

아래는 **실제 자산이 있어야 하는 것**이다. 생성하면 허위가 되거나 브랜드가 훼손된다.

| 분류 | 예 |
|------|---|
| 브랜드 자산 | 박성제 대표 프로필 카드 / 실적 배너(5,600+ · 97.2% · 572억+) / T.1555-2028 배너 / 상담사 프로필 / 공감 배너 |
| 기관 로고·간판 | 소상공인시장진흥공단 / SGI서울보증 / KFME / 신용보증재단 / 한국은행 |
| 정부 공식 홍보물 | 중기부·소진공 보도자료 첨부 카드뉴스 |
| 채널 캡처 | 유튜브 채널 화면 / 영상 썸네일 |

- 이 자리는 **번호를 비우고 대조표에 `★고정자산 직접 넣으세요`** 로 표시한다.
- 고정자산 파일을 `assets/` 에 모아주시면, 이후로는 해당 번호에 자동으로 복사해 넣는다.

## 4. 저품질 주의 — 스톡 비중

레포의 `naver-blog-publish` 스킬에 이미 적혀 있는 원칙이다.

> 직접 촬영 이미지 위주인가 (무료 스톡 도배 = 감점)

네이버는 직접 촬영 실사에 가산점을 주고, 어디서 본 듯한 스톡으로만 채운 글에 감점을 준다.
샘플 3·4에서 기관 간판 실사와 현장 사진이 섞여 있던 것도 같은 맥락으로 보인다.

그래서 이렇게 운용한다.

- 스톡만으로 전부 채운 글은 **가능하면 피한다.**
- 직접 촬영본이 있으면 **대표 이미지와 사례 장면만이라도** 그걸로 바꾼다.
- 대조표에 스톡 컷이 몇 개인지 알 수 있으니, 스톡 비중이 70%를 넘으면
  글을 넘길 때 **"직접 촬영본으로 교체 권장" 컷을 지목해 함께 알린다.**

## 5. 템플릿 선택

요청 내용에 따라 7개 중 하나를 고른다. 두 개를 섞지 않는다.

| 요청이 이런 것이면 | 쓸 템플릿 |
|---|---|
| 매장 운영·마케팅 노하우를 사례로 풀어달라 | 01 노하우 전달형 |
| 뭘 준비해야 하는지 실무 체크 순서를 달라 | 02 실무 체크형 |
| 승인 사례·전문성을 앞세워 신뢰를 보여달라 | 03 신뢰도 강조형 |
| 바뀐 제도·새 공고를 정확히 안내해달라 | 04 제도 안내형 |
| A와 B 중 뭐가 나은지 비교해달라 | 05 비교 판단형 |
| 이러면 안 된다는 걸 경고해달라 | 06 실패 경고형 |
| 자주 받는 질문을 모아 답해달라 | 07 질문 응답형 |

- 어느 쪽인지 애매하면 **고르기 전에 묻는다.** 임의로 정하지 않는다.
- 대표님이 번호로 지정하시면 (`3번으로 써줘`) 그대로 따른다.

## 6. 작성 후 처리

글을 만들고 나면 두 가지를 이어서 한다.

1. `posts/_variation-log.md` 에 행 추가 — 골격·어조·제목패턴·도입훅
2. `posts/_publish-log.md` 에 행 추가 — 상태 `대기` 로

발행은 대표님이 직접 하신다. 발행 후 알려주시면 `_publish-log.md` 의 상태를
`발행완료` 로 바꾸고 발행일·URL 을 채운다.
