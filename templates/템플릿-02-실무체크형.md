# 템플릿 02 — 실무 체크형

출처 샘플: 정책자금 신청 전 확인할 3가지

이 문서 하나만 보고 글을 쓸 수 있도록 자체 완결로 작성한다. 다른 템플릿을 참조하지 않는다.

---

## 1. 글 구조 (이 순서 그대로)

| 순서 | 요소 | 분량 |
|------|------|------|
| 1 | 도입 — 흔한 행동 3줄 나열 (**이미지 없이 텍스트로 시작**) | 3줄 |
| 2 | `대부분 이렇게 시작합니다.` | 1줄 |
| 3 | 훅 — 문제 선언 (빨강 + 밑줄) | 2줄 |
| 4 | `왜 그럴까요?` (빨강 이탤릭) | 1줄 |
| 5 | **예고형 문장** — 읽으면 뭘 알게 되는지 | 2줄 |
| 6 | **이미지** | 1컷 |
| 7 | 되묻는 질문 (이탤릭) + 공감 | 2줄 |
| 8 | **비유** — 일상 사례로 원리 설명 | 2~3줄 |
| 9 | **용어 정의 블록** (형광펜 3줄) | 3줄 |
| 10 | **권위 수치** — 누적 실적 언급 | 2줄 |
| 11 | **이미지** | 1컷 |
| 12 | **소제목 1** → 본문 → **이미지** | 본문 6~10줄 |
| 13 | 사례 — 수치 포함 | 5~8줄 |
| 14 | 실무 정보 (기관·비용) → **이미지** | 5~6줄 |
| 15 | **소제목 2** → 본문 → **이미지** | 본문 8~12줄 |
| 16 | **소제목 3** → 본문 → **이미지** | 본문 10~14줄 |
| 17 | 요약 — `짚어드리면요.` + 3줄 (파랑) | 6줄 |
| 18 | **이미지** | 1컷 |
| 19 | **면책 문구** | 2줄 |
| 20 | **이미지** | 1컷 |
| 21 | 재권유 + 회사 소개 + CTA | 8줄 |
| 22 | 네이버폼 링크 카드 (임베드) | 1개 |

이미지 총 8컷. **대표 이미지 없이 텍스트로 시작한다.**

---

## 2. 줄 규격

- 한 줄 **7~31자** (공백 포함). 최빈 11~25자.
- **30자를 넘기지 않는 것을 기본으로 한다.** 짧게 끊는 것이 이 템플릿의 인상이다.
- 의미 단위로 자른다. 문장이 끝나면 줄을 바꾼다.
- 줄 끝에 마침표를 찍는다.

## 3. 문단 규격

- 한 문단 **1~3줄**. 4줄 이상 금지.
- 문단 사이 빈 줄 **1개**.
- 소제목 앞뒤는 빈 줄 **2개 이상**.

---

## 4. 소제목

- 개수: **정확히 3개**
- 형식: `1. 조회부터 하십시오.`
  - 아라비아 숫자 + 마침표 + 공백
  - 문장형 + `~하십시오` 명령 종결 + 마침표
  - 길이 **9~14자**. 짧고 단호하게.
- 표시: 좌측 세로 막대 + 볼드

---

## 5. 강조 (5종)

| 방식 | 쓰는 곳 |
|------|--------|
| 빨강 글씨 | 문제 선언, 핵심 주장, 되묻는 질문 |
| 노랑 형광펜 | 용어 정의, 기억해야 할 수치 |
| 파랑 글씨 | 마무리 요약 3줄 |
| 밑줄 | 경고성 문장 |
| 이탤릭 | 되묻는 질문, 도입 훅 |

- 구절 단위로도 칠한다.
- 도입 훅(`왜 그럴까요?`)은 빨강 + 이탤릭.
- **마무리 요약 3줄은 파란 글씨로 통일한다.**

---

## 6. 이미지 명세

| # | 성격 | 비율 | 위치 |
|---|------|------|------|
| 1 | 고민하는 인물 (어두운 조명, 서류) | 가로 | 도입부 끝 |
| 2 | 체크리스트 사물 (노트·펜) | 가로 | 정의 블록 뒤 |
| 3 | 스마트폰 화면 (금액·조회) | 가로 | 소제목1 끝 |
| 4 | 모니터·서류 화면 | 가로 | 실무 정보 뒤 |
| 5 | 계산·검토 사물 (계산기·형광펜) | 가로 | 소제목2 끝 |
| 6 | 계획 작성 (노트에 쓰는 손) | 가로 | 소제목3 끝 |
| 7 | 연락·알림 (스마트폰 든 인물) | 가로 | 요약 뒤 |
| 8 | 상담 장면 (두 사람, 노트북) | 가로 | 면책 뒤 |

- **전부 가로형.** 세로형을 쓰지 않는다.
- **전부 스톡·생성 계열.** 특정 매장 실사가 아니다. 사물 위주, 인물은 얼굴을 흐리거나 부분만.
- 전부 좌측 정렬, 우측 여백.
- **8컷 모두 생성 가능.** 브랜드 고정자산이 들어가지 않는다.

## 7. 이 템플릿의 핵심 장치 5가지

### 예고형 문장
도입 훅 직후 배치. 이탈 방지용.
```
이 글 끝까지 읽으면 3분 안에
신청 전에 뭘 봐야 하는지 알게 됩니다.
```

### 비유
어려운 원리를 일상으로 옮긴다.
```
수술 전에 피검사부터 하잖아요.
수치 하나 걸리면 그날 수술은 취소됩니다.

정책자금 심사도 똑같습니다.
```

### 용어 정의 블록
형광펜 3줄. 검색·AI 인용을 노린다.
```
(용어)이란
(주체)가 (조건)한 (대상)에게
(혜택)해주는 (것)입니다.
```

### 권위 수치
사례 앞에 배치한다.
```
컨설팅 누적 5,600건 이상 보면서
가장 많이 걸린 지점은 늘 같았습니다.
```

### 면책 문구
마무리 직전 고정 위치.
```
단, 기관별 심사 기준과 공고는 해마다 갱신되니
신청 전 최신 공고는 꼭 확인하세요.
```

---

## 8. 사례 규격

- 이동 거리·금액·기간 같은 **구체 수치**를 박는다 (왕복 400km, 2억 2천, 열람 700원).
- 실패 → 원인 → 교훈 순서.
- 호칭은 `대표님`.
- 기관명·서비스명을 실명으로 적는다 (나이스, 토스, 카카오뱅크, 홈택스, 위택스, 인터넷등기소).

## 9. 마무리 골격

```
짚어드리면요.
(핵심 주장 2줄)

(요약 1)          ← 파랑
(요약 2)          ← 파랑
(요약 3).         ← 파랑

단, (변동 요인)은 해마다 갱신되니
(확인 행동)은 꼭 확인하세요.

혹시 (장애물) 때문에
(포기 상태)이시면
(첫 행동)부터 한번 봅시다.
지금 안 보면 내년에도 같은 자리입니다.

저희 한국중소기업비즈니스센터는
정책자금과 정부 지원금은 물론
심사 준비 고민까지 함께 풀어드립니다.

혼자 하기 어려우시면 아래 네이버폼 남겨주세요.
저 박관장이 꼼꼼히 보고 연락드리겠습니다.
```

## 10. 금지

- 인용부호 `" "` 금지.
- 이모지 금지.
- 마크다운 기호 금지.
- 4줄 이상 문단 금지.
- **불릿 리스트 금지.** 나열은 줄바꿈으로만 처리한다.
- 공감 배너 넣지 않는다.
- 세로형 이미지 넣지 않는다.
