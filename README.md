네이버 블로그 글쓰기 작업 레포입니다.
Claude가 네이버 검색 상위노출(C-Rank, D.I.A.+)에 맞춰 글을 작성하도록
**전용 스킬 세트**를 학습시켜 두었습니다.

## 📦 설치된 스킬 (`.claude/skills/`)

네이버 블로그 작성을 **3단계 파이프라인**으로 자동화합니다.

| 단계 | 스킬 | 하는 일 | 이렇게 부르면 발동 |
|------|------|--------|------------------|
| ① 키워드 | `naver-seo-keyword` | 메인/세부/연관 키워드, 검색 의도 분석, 제목·소제목 후보 | "키워드 잡아줘", "제목 추천" |
| ② 작성 | `naver-blog-writer` | 역피라미드 구조 본문, 톤앤매너, 금지표현 필터, 이미지/영상 배치 | "블로그 글 써줘", "후기 글 작성" |
| ③ 발행 | `naver-blog-publish` | 최종 체크리스트, 태그 정리, 저품질 점검, 발행 타이밍 | "발행 전 점검", "태그 정리" |

### ★ 박관장 전용 스킬 (정책자금 콘텐츠)

| 스킬 | 하는 일 | 이렇게 부르면 발동 |
|------|--------|------------------|
| `naver-seo-geo-blog` | 한국중소기업비즈니스센터 박관장 1인칭 회상조 / SEO·GEO·홈피드 3중 최적화 / 5단계 워크플로우(레퍼런스→사례제안→컨펌→본문 1200~1300자) / 제목 POOL T1~T6 / 본문 골격 S1~S3 로테이션 / 변주 로그 | "박관장 글", "정책자금 블로그", "폐업지원금/새출발기금 포스팅" |
| `policy-fund-factcheck` | 발행 전 정책자금 수치·요건 팩트체크, 단정·과장 거르기, 면책 문구 삽입 (저품질·법적 리스크 차단) | "팩트체크", "이 글 발행해도 돼?" |
| `park-voice-linter` | 박관장 보이스 규칙(인용부호 0·burstiness·억지비유 0·사례 4축·1200~1300자) 출력물 채점·검수 | "보이스 검수", "톤 점검", "린트" |
| `content-calendar` | 키워드 10~20개를 골격·제목패턴·발행일에 분산 배치(자기복제 차단) | "주제 기획", "콘텐츠 캘린더" |
| `naver-image-shotlist` | 글의 이미지 자리마다 직접촬영 구도 + 무료출처 검색어 + 캡션/alt | "샷리스트", "무슨 사진 찍어" |

> ⚠️ `naver-seo-geo-blog`는 **STEP3 사례 제안 → 컨펌 이후에만 본문을 씁니다.** 메인키워드 + 레퍼런스 이미지를 주고 시작하세요.
> 💡 권장 흐름: `content-calendar`(기획) → `naver-seo-geo-blog`(작성) → `park-voice-linter` + `policy-fund-factcheck`(검수) → `naver-image-shotlist`(이미지) → 네이버에 수동 발행 → **`posts/_publish-log.md` 에 발행일·URL 기록.**

## 🚀 사용법

Claude에게 그냥 자연어로 요청하면 적절한 스킬이 자동 실행됩니다.

```
"강남역 혼밥 맛집 주제로 블로그 글 써줘"
  → naver-seo-keyword(키워드·제목) → naver-blog-writer(본문) → naver-blog-publish(점검)
```

처음이라면 아래처럼 한 번에 맡겨도 됩니다.

```
"OO 주제로 네이버 블로그 포스팅 처음부터 끝까지 만들어줘"
```

## 📐 적용되는 네이버 SEO 원칙

- 검색 의도 충족 > 키워드 반복 (D.I.A.+ 로직)
- 평가 3축: 적합성 · 신뢰성 · 최신성
- 분량 1,500~2,000자, 역피라미드(핵심 먼저)
- 직접 촬영 이미지 10장+ / 동영상 15초+ 가산점
- 협찬·체험단 표기 필수, 과장·의료 단정 표현 금지

## 📒 두 개의 원장

`posts/` 아래 두 기록 파일이 서로 다른 질문에 답한다. **둘 다 매번 갱신한다.**

| 파일 | 답하는 질문 | 언제 적나 |
|------|-----------|----------|
| `_variation-log.md` | 이 글을 **어떻게** 썼나 (골격 S·어조 V·제목패턴 T·도입훅) | 글을 **쓴** 직후 |
| `_publish-log.md` | 이 글이 **올라갔나** (상태·발행일·URL) | 글을 **발행한** 직후 |

전자는 자기복제를 막고, 후자는 중복 발행과 누락을 막는다.
`_publish-log.md` 는 현재 전 행이 `미확인` 이다 — 과거 36편의 실제 발행 여부를 아직 대조하지 않았다.

## 📁 폴더 구조

```
길라잡이.md                  # ★ 진입점 — 작업별 순서와 규칙 권한표
templates/                   # 시각 서식의 주인 (템플릿 7종 + 운영규칙)
.claude/skills/
  ├─ naver-seo-keyword/      # 키워드·검색의도 설계
  ├─ naver-blog-writer/      # 본문 작성 (+ assets/forbidden-words.txt 금지어 목록)
  ├─ naver-blog-publish/     # 발행 전 점검
  ├─ naver-seo-geo-blog/     # ★ 박관장 전용 본문 (SEO·GEO·홈피드 3중 최적화)
  ├─ policy-fund-factcheck/  # ★ 정책자금 수치·요건 팩트체크
  ├─ park-voice-linter/      # ★ 박관장 보이스 규칙 채점·검수
  ├─ content-calendar/       # ★ 주제 분산 배치(자기복제 차단)
  └─ naver-image-shotlist/   # ★ 이미지 구도·출처·캡션 설계
posts/                       # 작성한 글 (YYYY-MM-DD-주제.md)
  ├─ _variation-log.md       # 골격·어조·제목패턴 변주 기록 (자기복제 차단용)
  ├─ _publish-log.md         # 발행 원장 — 실제 네이버 발행 여부·발행일·URL
  └─ _archive/               # 구 포맷·중복 등 보류된 글
```
