# Naverblog

네이버 블로그 글쓰기 작업 레포입니다.
Claude가 네이버 검색 상위노출(C-Rank, D.I.A.+)에 맞춰 글을 작성하도록
**전용 스킬 세트**를 학습시켜 두었습니다.

## 📦 설치된 스킬 (`.claude/skills/`)

네이버 블로그 작성을 **3단계 파이프라인**으로 자동화합니다.

| 단계 | 스킬 | 하는 일 | 이렇게 부르면 발동 |
|------|------|--------|------------------|
| ① 키워드 | `naver-seo-keyword` | 메인/세부/연관 키워드, 검색 의도 분석, 제목·소제목 후보 | "키워드 잡아줘", "제목 추천" |
| ② 작성 | `naver-blog-writer` | 역피라미드 구조 본문, 톤앤매너, 금지표현 필터, 이미지/영상 배치 | "블로그 글 써줘", "후기 글 작성" |
| ③ 발행 | `naver-blog-publish` | 최종 체크리스트, 태그 정리, 저품질 점검, 발행 타이밍 | "발행 전 점검", "태그 정리" |

## 🚀 사용법

Claude에게 그냥 자연어로 요청하면 적절한 스킬이 자동 실행됩니다.

```
"강남역 혼밥 맛집 주제로 블로그 글 써줘"
  → naver-seo-keyword(키워드·제목) → naver-blog-writer(본문) → naver-blog-publish(점검)
```

처음이라면 아래처럼 한 번에 맡겨도 됩니다.

```
"OO 주제로 네이버 블로그 포스팅 처음부터 끝까지 만들어줘"
```

## 📐 적용되는 네이버 SEO 원칙

- 검색 의도 충족 > 키워드 반복 (D.I.A.+ 로직)
- 평가 3축: 적합성 · 신뢰성 · 최신성
- 분량 1,500~2,000자, 역피라미드(핵심 먼저)
- 직접 촬영 이미지 10장+ / 동영상 15초+ 가산점
- 협찬·체험단 표기 필수, 과장·의료 단정 표현 금지

## 📁 폴더 구조

```
.claude/skills/
  ├─ naver-seo-keyword/   # 키워드·검색의도 설계
  ├─ naver-blog-writer/   # 본문 작성 (+ assets/forbidden-words.txt 금지어 목록)
  └─ naver-blog-publish/  # 발행 전 점검
posts/                    # 작성한 글 저장 (YYYY-MM-DD-주제.md)
```

## ⚙️ 커스터마이징

- **금지어 추가**: `.claude/skills/naver-blog-writer/assets/forbidden-words.txt` 편집
- **톤/분야 고정**: 자주 쓰는 톤·분야·금지표현은 각 `SKILL.md`에 추가하면 매번 설명할 필요 없이 자동 적용됩니다.
