## 5. 알려진 병목·한계

| 무엇 | 영향 | 대응 |
|---|---|---|
| 브라우저 확장 연결이 끊길 때가 있다 | 웹 캡처·Pexels 검색 | headless 크롬(Playwright)으로 대체 — 길라잡이 5-5 |
| 소진공 웹 금리표는 공지사항 PDF 보다 늦게 바뀐다 | 금리를 웹에서만 보면 틀린다 | **분기 초(1·4·7·10월 10일 전후)엔 공지사항 첨부 PDF 부터** |
| 공고PDF캡처 `칸:` 은 실선 표만 읽는다 | 점선 칸 구분 표는 칸 전체 테두리 ✗ | 한 줄 칸은 그냥 글자 기준으로 |
| 반전 B · 타임라인 C 카드는 본문에 안 쓴 사진이 하나 더 필요 | 사진이 없으면 그 디자인을 건너뛴다 | Pexels 에서 한 장 더 받아 `"photo"` 로 |
| 정책자금용 브랜드 자산이 8종뿐 | 이웃 3편 반복 금지라 순환이 빠듯하다 | 새 배너·사진이 생기면 `assets/브랜드/` 에 |
| 카드 글꼴은 이 PC 에 깔린 것 기준 | 다른 PC 에선 맑은 고딕으로 바뀐다 | 길라잡이 6-7 |
| 같은 틀끼리 구조 유사도 0.75~0.81 | 틀이 같으면 자연스럽다. 같은 주 같은 틀 짝은 처음에 0.92~0.95까지 나왔다 | 다이얼(사진을 항목 앞/뒤, 짝 사진 사이 문단 위치, 인용 위치, 사례 위치). 줄을 나누면 문단 수가 바뀌어 다시 올라가니 줄 정리 뒤 한 번 더 검사 |
| 정책자금 주제가 4주째라 겹치기 쉽다 | 청년고용·성실상환·5년 3회 등은 이미 씀 | 새 주제는 발행 기록 «주제» 칸과 `posts/` 를 먼저 grep. 컨설팅 주제는 `posts/*노하우*` 24편과 겹치지 않게 |
| Pexels 한국 장면이 적다 (빨래방·야구장·김밥) | 외국어 안내판·상표가 섞여 들어온다 | 받은 사진을 원본 크기로 열어 글씨를 본다. 잘라서 안 되면 글씨 없는 사진으로 바꾼다 |
