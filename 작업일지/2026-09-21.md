실제로 고친 충돌 6건:
- **제목 길이** — keyword/writer 는 25자 권장, geo-blog 는 25자 이하 금지. 정면충돌이었다
- 이미지 컷 수 — shotlist 6~13장 / publish 10장 이상 → 템플릿이 정하도록
- 이미지 조달 — shotlist 의 "이미지를 가져오지 못한다" 전제가 이미 틀렸다
- 이미지 표기 — `[이미지 N]` / `[이미지: 설명]` → `(사진N)` 통일
- 본문 분량 — 박관장 1200~1300 과 범용 1500~2000 분리
- writer 가 범용 전용임을 명시

> **원칙: 한 값은 한 곳에만 적는다.** 복사하면 어긋난다. 제목 길이가 실제로 그렇게 어긋났다.
> 그래서 충돌을 고칠 때 값을 옮겨 적지 않고 "주인에게 위임" 문구로 처리했다.

### 사례 정책 — 대표님 결정
**사례는 창작으로 간다.** 실제 상담 건을 받아 쓰지 않는다.
STEP3 컨펌을 사례 진위 확인 목적으로 붙잡지 않는다.

지키는 것:
- 실존 상호·실명·특정 가능한 정보를 넣지 않는다
- `포스팅.txt` 하단에 `■ 사례 — 창작 사례입니다` 를 남긴다
- **수치는 창작하지 않는다.** 확인 못 한 값은 `■ ★수치 확인 필요` 로 분리해 넘긴다

> 표시광고법 관련 권고(`재구성한 예시입니다` 한 줄 삽입)는 문서에만 남기고 미적용.

## 5. 이미지 — 네 번 갈아엎었다

이 날 작업의 대부분이 여기 들어갔다. 순서대로 남긴다.

### 1차 · AI 생성 (폐기)
스톡 사이트 자동 조달이 막혀(Unsplash 봇 차단, Pexels 빈 응답) Codex image_gen 으로 41컷 생성.
→ 대표님이 **"AI 말고 실사"** 를 요구. 폐기.

### 2차 · Openverse CC0 (실패, 복구함)
API 없이 되는 CC0 전문 검색을 썼는데 **풀이 얕았다.**
"반려 서류" 자리에 탑 사진, "재무제표" 자리에 고문서가 들어왔다.
20컷이 오염됐고 **git 에서 복구**했다. 커밋해둔 게 여기서 살렸다.

### 3차 · Pexels (성공)
**API 키도 계정도 없이 해결.** 검색 페이지는 브라우저로 열어 이미지 주소만 긁고,
다운로드는 CDN 에서 직접 받는다. CDN 에는 봇 차단이 없다.

→ 이후 대표님이 **"이미지랑 내용이 안 맞는다"** 고 지적. 맞는 지적이었고 원인은 검색어였다.
`computer monitor office desk` 같은 뭉뚱그린 검색어를 던져서, 어느 문단에 놓아도
말이 되는 대신 어느 문단에도 딱 맞지 않는 사무실 사진이 한 글에 8장씩 깔렸다.

**검수 방법도 틀렸다.** 썸네일만 보고 "사무실 사진이니 맞겠지" 하고 넘겼다.
→ 이미지 옆에 실제 본문을 붙인 **대조 시트**를 만들어 40컷을 다시 봤다.

문장 단위로 검색어를 다시 짜서 25컷 교체. 2차 검수에서 4컷을 더 잡았는데 전부 같은 원인이었다:
독일 선거 우편물(Wahlbrief), 미국 1040 세금양식, 폴란드 즈워티 지폐, 달러 다발.

### 4차 · 한국 장면 + 실제 공고
**Pexels 검색어 앞에 `korean` 을 붙이면 결과가 완전히 달라진다.**
이걸 처음부터 안 해본 게 실수였다. 사람·매장 컷 6장을 한국 장면으로 교체.
`closed shop korea` → 금정정밀 간판과 전화번호가 보이는 실제 한국 폐업 점포.

그리고 대표님 의견: **"사진별로 말고 실제 서류·로고·공고·포스터를 쓰자."**
맞는 방향이다. 샘플 3·4번 실제 글도 기관 간판과 정부 카드뉴스가 뼈대였다.
→ 소진공 2026년 정책자금 공고에서 세부 지원요건 표를 캡처해
`0921-2 사진4`(비워뒀던 비교표 자리)에 넣었다.

**그 과정에서 본문 오류를 하나 잡았다.**
0921-3 Q1 의 신용점수 기준을 744점으로 썼는데, 공고 원문은 `NCB 839점 이하` 였다.
실제 공고를 쓰면 이미지만 좋아지는 게 아니라 **본문 수치도 같이 검증된다.**

### 이미지 출처 — 시도 결과

| 출처 | 결과 |
|---|---|
| **Pexels** | ✅ 현재 주력. 브라우저로 주소 수집 → CDN 직접 다운로드 |
| **소진공 (semas.or.kr)** | ✅ 이미지가 쿼리스트링 없는 경로. 공고 페이지 캡처 가능 |
| Unsplash | 2순위로 스크립트에 넣어둠. 이번엔 Pexels 로 다 채워져 미사용 |
| 공유마당 | ❌ 썸네일 6KB, 원본은 로그인 필요 |
| 공공누리 · 정책브리핑 | ❌ 이미지 주소에 쿼리스트링 → 확장이 반환 차단 |
| Openverse CC0 | ❌ 풀이 얕음 |
| 구글 이미지 | ❌ 저작권이 살아 있는 타인의 저작물. 쓰지 않는다 |

> 구글 이미지 건은 대표님이 두 번 요청하셨고 두 번 다 하지 않았다.
> 블러를 씌워도 원저작물 권리는 그대로이고(2차적저작물작성권 자체가 원저작자 권리),
> "몇 퍼센트 이상 바꾸면 된다"는 규정은 법에 없다.
> 합법인 2차창작은 **구도·아이디어만 참고해 새로 만드는 것**이다.
